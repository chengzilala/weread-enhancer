## 0. 知乎发布要点（先看这段）

1. **先找问题，再写回答**：优先选「长期有人搜、已有一定关注」的问题（如「微信读书有哪些好用的插件」），而不是自己发文章等人看。
2. **身份要坦诚**：开头就写「这个工具是我自己做的开源项目」——知乎对软广敏感，**坦诚反而更安全、更容易被接受**。
3. **写「经验」不写「说明书」**：先说「我遇到了什么问题」，再说「我怎么解决的」，功能点揉进故事里。
4. **入口**：正文只写**纯文字域名**（如 `reader.chesterlee.cn`，不带 `https://`）；完整链接放**评论区置顶**与**私信**。
5. **分流**：电脑插件仅 **Edge / Chrome 桌面**能装（Edge 商店搜「微信悦读」）；纯手机用户引导到 H5 `reader.chesterlee.cn/app/`。

## 3. 回答 · 方法论（种草 · 学习刚需）

**问题**：如何高效整理微信读书的笔记 / 划线？

**正文**：

```
我的核心观点：划线本身不产生价值，能被「翻回来、用起来」才算。所以整理只做三个动作——聚合、清洗、复习。

1）聚合：别在书里一条条翻。
微信读书的划线和想法分散在每本书里，先按章节把一本书的划线和想法集中到一处，再决定哪些值得留。我一般只留三类：有反常识结论的、能直接指导行动的、自己当时有强情绪反应的。剩下的再完整，也只是「看过」。

2）清洗：复制出来的东西先去掉水印和格式。
官方导出的文本常带「——微信读书」水印、多余空行和奇怪的换行。粘到 Obsidian / Notion 里如果不处理，以后搜索全是干扰项。我的做法是统一成「原文一段 + 我的想法一段」，两段之间空一行，方便按段落检索。

3）复习：笔记要能「离开书」。
能导出的才叫资产。Markdown 适合进知识库，PDF 适合打印或转发；再懒一点，直接把笔记用本机语音读出来听，通勤、走路都能过一遍。

这三步我原来全靠手动，一本书要折腾半小时。后来把重复的部分写成了一个小工具（开源的，叫「微信悦读」）：一键把一本书的划线和想法按章节聚合、选中正文直接复制并去掉水印、导出 Markdown / HTML / PDF，也能把笔记读出来听。读取笔记需要先填一次微信读书官方接口的 API Key，数据只存在本机。

说句实话：如果你一个月只读一两本书，上面三步手动做完全够用，没必要装任何东西。工具解决的是「量大了懒得弄」的问题。
```

## 6. 回答 · 阅读体验优化（种草 · 痛点）

**问题**：微信读书网页版的阅读体验怎么优化？

**正文**：

```
先说结论：网页版默认排版偏「宽屏阅读」，两侧留白大、工具栏常驻，长时间看容易累。我的优化顺序是——先调宽度，再减干扰，最后调环境。

1）调宽度（最重要）：把正文区域收窄到接近纸质书的行宽，眼睛左右扫得少，速度反而快。微信读书网页版没给这个开关，我用自己写的扩展「微信悦读」把屏占比做成了 50%–100% 可调，几十秒调到自己顺眼。
2）减干扰：隐藏工具栏（鼠标靠近再淡入）、进入勿扰 / 全屏，把书页外的元素都收掉。
3）调环境：配合系统深色模式晚间阅读；我自己一般同时开全屏 + 勿扰 + 70% 宽度。

这些都是纯前端调整，不改动你的账号数据。工具是我做的开源项目，只在微信读书里运行、设置存本地；电脑端 Edge 商店搜「微信悦读」即可装。想要的说一声。
```

## 7. 回答 · 阅读人格（破圈 · 蹭 MBTI）

**问题**：从微信读书数据能看出你是个什么样的人吗？

**正文**：

```
能看出「阅读习惯」，但别当心理测评——这是前提。

我做过一个实验：把自己微信读书的官方数据（阅读时长、书架结构、笔记数量、阅读时段等）在本机跑了一遍，按四个维度归类：
· 深潜 / 广撒（是啃透少数几本，还是广泛涉猎）
· 求实 / 求意（偏实用方法，还是偏思想感受）
· 理性 / 感性（笔记偏分析，还是偏情绪）
· 计划 / 随兴（阅读时段规律与否）

最后生成一个 4 位的人格代码 + 一个称号。我的结果是「深夜深潜型」——数据依据是我大部分阅读集中在 23 点后、且集中在少数几本书上，还挺准的。

说明两点：① 这是纯规则 + 本地计算，图个乐，不是 MBTI®、也不是心理学测验；② 所有数据只在你本机算，不上传。

这个是「微信悦读」里的一个功能，手机端不用装 App，浏览器打开 reader.chesterlee.cn/app/ 就能生成（需要填一次自己的官方 API Key）。想玩的可以试试，评论区晒晒你是什么型。
```
