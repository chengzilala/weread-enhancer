# 数据备份与恢复（v0.25.0） — 测试验收清单

> 前置：扩展管理页「重新加载」插件 → 打开一本书的阅读页（`weread.qq.com/web/reader/…`）→ 悬浮球展开主菜单 →「🗄️ 数据备份」。
> 排错统一看控制台 `[backup]` 开头日志（纯本机读写，全程**不联网、不上传**）。
> 说明：备份文件**绝不含**任何 API Key / 匿名标识；换设备请重新粘贴一次 Key。
> 建议准备：先在「🔎 找书」给几本书打标签、读一会书产生阅读统计，便于验证「有数据」分支。

## 一、入口与面板

- [ ] **1.1** 主菜单「设置」分组内出现「🗄️ 数据备份」入口，紧邻「阅读设置 / 调试日志」
- [ ] **1.2** 点击后弹出「🗄️ 数据备份」弹层，含顶部说明条、「本机数据一览」、四个操作按钮、底部 Key 安全提示
- [ ] **1.3** 点右上角 `×` 或点击弹层外空白处可关闭
- [ ] **1.4** 与其它面板互斥：打开本面板时，其它面板不叠显

## 二、本机数据一览

- [ ] **2.1** 已打过标签：「找书标签」显示「N 本 · 更新于 MM-DD HH:mm」
- [ ] **2.2** 有阅读统计：「阅读统计」显示「累计 X 小时 · 明细 N 天」
- [ ] **2.3** 「插件设置」显示「已保存」；「新手引导版本」显示版本号
- [ ] **2.4** 从未产生某项数据时，该项显示「暂无」且整体置灰（`.is-empty`）

## 三、导出备份

- [ ] **3.1** 点「⬇️ 导出备份」→ 浏览器下载文件，文件名形如 `微信悦读-数据备份-20261007.json`
- [ ] **3.2** 打开文件：含 `app:"weread-enhancer"`、`schemaVersion`、`appVersion`、`exportedAt`、`data`
- [ ] **3.3** `data` 内**只含** `wreBookTags` / `wreReadingStats` / `wreState` / `wreOnboardingVersion`
- [ ] **3.4** 文件中**不含**任何 `wrk-` / `sk-` / Key / 匿名标识（红线核对）
- [ ] **3.5** 完全无数据时也能导出，面板提示「已导出空备份：暂无可备份的数据项（4 项均为空）」

## 四、导入恢复 · 合并

- [ ] **4.1** 点「⬆️ 导入（合并）」选择备份文件 → 提示「已合并恢复：N 项数据」并出现「🔄 刷新页面」按钮
- [ ] **4.2** 合并语义：标签取**并集**（本机原有 + 文件里的都保留，不重复）
- [ ] **4.3** 合并语义：阅读统计按日期**相加**、`lastReadAt` 取大、进度取较大者
- [ ] **4.4** 合并语义：插件设置按「文件覆盖本机」逐项写入
- [ ] **4.5** 点「🔄 刷新页面」→ 页面重载后，设置 / 统计按导入结果生效

## 五、导入恢复 · 覆盖

- [ ] **5.1** 点「⬆️ 导入（覆盖）」→ 提示「已覆盖恢复：N 项数据」
- [ ] **5.2** 覆盖语义：先清空 A 类，再整体写入文件内容（本机原有标签被文件内容替换）

## 六、清空用户数据

- [ ] **6.1** 点「🗑️ 清空本机用户数据」→ 弹出二次确认
- [ ] **6.2** 确认后提示「已清空…」，数据一览各项变为「暂无」并置灰
- [ ] **6.3** 取消确认时不执行任何清空

## 七、异常与边界

- [ ] **7.1** 选一个非本插件 JSON（如随便一个 `.json`）导入 → 提示「文件头缺少 app 标识」，不写入、不报错
- [ ] **7.2** 选一个缺 `schemaVersion` 的文件 → 提示缺失 schemaVersion，不写入
- [ ] **7.3** 选一个非 JSON 文件 → 提示「文件无法解析」，不报错

## 八、冒烟闭环（导出 → 清空 → 导入还原）

- [ ] **8.1** 先「导出备份」→ 再「清空本机用户数据」→ 再「导入（覆盖）」同一文件 → 刷新后标签 / 统计 / 设置全部还原
- [ ] **8.2** 全程无网络请求（DevTools Network 面板静默），未新增任何浏览器权限
