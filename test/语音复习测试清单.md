# 语音复习（M14 · v0.24.0） — 测试验收清单

> 前置：扩展管理页「重新加载」插件 → 打开一本书的阅读页（`weread.qq.com/web/reader/…`）→ 悬浮球展开主菜单 → 打开「📝 笔记」（需已配置 `wrk-` Key）。
> 排错统一看控制台 `[TTS]` 开头日志（本机朗读，全程不联网、不上传）。
> 说明：语音能力由**浏览器内置**提供，不用联网、不用配置任何外部服务；若浏览器无中文语音，发音可能生硬或走默认语音。

## 一、入口与按钮（A 档）

- [ ] **1.1** 打开「📝 笔记」面板，工具栏出现「▶ 连续朗读」「▶ 听全部」「▶ 只听想法」三个按钮
- [ ] **1.2** 每条划线 / 想法条目右上角出现圆形「▶」小按钮，不遮挡正文、不压住时间
- [ ] **1.3** 工具栏显示一句提示「🔊 朗读在本机合成，不联网、不上传；不提供音频导出。」
- [ ] **1.4** 面板打开时底部**不**显示播放控制条（未开始朗读）

## 二、单条朗读（A 档）

- [ ] **2.1** 点某条划线的「▶」，立刻朗读该条正文；按钮变「⏸」，该条左边框高亮
- [ ] **2.2** 朗读中再点同一条的「⏸」→ 暂停（按钮变「▶」）；再点 → 从暂停处继续（按钮变「⏸」）
- [ ] **2.3** 朗读中直接点另一条的「▶」→ 自动停掉上一条，改读新的一条（同一时刻只播一条）
- [ ] **2.4** 想法条目「▶」：先读原文摘录、再读「我的想法」两部分
- [ ] **2.5** 读到条目末尾自然结束：按钮恢复「▶」，高亮消失，底部控制条自动隐藏
- [ ] **2.6** 长划线（无标点、上百字）能**完整读完**，不被截断（分段朗读生效）

## 三、连续朗读与控制条（A 档）

- [ ] **3.1** 点「▶ 连续朗读」：从当前列表第一条开始，按**章节顺序 / 当前可见顺序**逐条朗读
- [ ] **3.2** 底部出现控制条，显示「第 N / 共 M 条」随播放前进
- [ ] **3.3** 「⏸ 暂停」可暂停、再点变「▶ 继续」可继续
- [ ] **3.4** 「⏭ 下一条」跳到下一条；「⏮ 上一条」回到上一条
- [ ] **3.5** 「⏹ 停止」立即停止，控制条隐藏，计数清空
- [ ] **3.6** 连续朗读中，读到每条会自动滚动到该条（`scrollIntoView`）
- [ ] **3.7** 在「想法/批注」Tab 点「▶ 连续朗读」：只读当前 Tab（想法）的可见条目

## 四、B 档（听全部 / 只听想法）

- [ ] **4.1** 点「▶ 听全部」：本书**划线 + 想法**一起排队朗读（划线在前、想法在后，各按章节顺序）
- [ ] **4.2** 点「▶ 只听想法」：只朗读自己写的想法 / 批注（跳过划线）
- [ ] **4.3** 该书没有想法时点「▶ 只听想法」：Toast 提示「这本书还没有想法/批注」，不报错
- [ ] **4.4** 该书笔记为空时点「▶ 听全部」：Toast 提示「这本书还没有可朗读的笔记」，不报错

## 五、与搜索联动

- [ ] **5.1** 搜索出「找到 N 条匹配」后点「▶ 连续朗读」：只朗读**搜索结果**里的条目
- [ ] **5.2** 搜索框输入 / 清空、切换 Tab 时：朗读**立即停止**（列表重绘，避免读到错位内容）

## 六、停止与边界（14.3.3）

- [ ] **6.1** 朗读中点面板「×」关闭 → 立即停止，无声继续
- [ ] **6.2** 朗读中切到别的浏览器标签页 / 最小化（页面不可见）→ 立即停止，不在后台偷偷播
- [ ] **6.3** 朗读中在阅读页按空格 / D / F / `?` 等快捷键 → 不被「听」抢走，正常生效
- [ ] **6.4** 多开两个阅读页各自朗读：互不串音（不做跨页同步）
- [ ] **6.5** 朗读过程中页面控制台无报错；日志有 `[TTS]` 前缀记录（开始朗读 / 停止 / 完成）

## 七、降级与文案

- [ ] **7.1** 浏览器不支持 `speechSynthesis`：条目「▶」与三个朗读按钮全部隐藏，工具栏给一句中文说明，其余笔记功能不受影响
- [ ] **7.2** 界面文案只用「朗读 / 听」，**不出现**「听书 / 电台 / 节目」
- [ ] **7.3** 界面**不出现**「云端合成 / 上传」字样；控制条明示「本机朗读 · 不联网、不上传」
- [ ] **7.4** 全程无音频文件生成 / 无下载按钮（**不提供音频分享 / 导出**）
