装到桌面，像 App 一样用（电脑 / 手机）

手机上的 H5 网页版和微信小程序，电脑上的 H5 网页版，都能「装到桌面」——从桌面图标一点就打开，用起来就像一个独立的 App，不用每次翻浏览器书签、也不用翻微信找入口。

这个用法很多人不知道，所以单独写一篇。照着下面的步骤做，一两分钟就能装好。

先分清你要装的是哪一个

  • 你用的是电脑浏览器打开的 H5 网页版（网址以 /app/ 结尾）→ 看「一、电脑」；
  • 你用的是手机浏览器打开的 H5 网页版 → 看「二、手机」；
  • 你用的是微信里的「悦读且住」小程序 → 看「三、微信小程序」。

不确定就都扫一眼，很快。

一、电脑（Windows / Mac）：装成桌面应用

H5 是纯网页，用浏览器的「安装应用」功能就能固定成桌面应用，和装软件一样。

  1. 用 Chrome 或 Edge 打开 H5 页面（网址以 /app/ 结尾）。
  2. 看浏览器地址栏最右侧：出现「安装」图标（一个小方块加向下箭头）就点它；没有的话点右上角「⋮」，在菜单里选「安装 微信悦读…」。
  3. 在弹出的窗口里点「安装」。Windows 上会在「桌面 / 开始菜单」出现图标；Mac 上会在「启动台 / 应用程序」出现图标。
  4. 之后点图标打开就是独立窗口，没有地址栏，和 App 一样。

Mac 上用 Safari

Safari 也支持：点菜单栏「文件」→「添加到程序坞」（需 macOS 14 及以上）。

二、手机：H5 网页版加到桌面

H5 是纯网页，用浏览器的「添加到主屏幕 / 安装应用」功能固定到桌面即可。

iPhone / iPad（Safari）

  1. 用 Safari 打开 H5 页面。
    • 如果你是在微信里点开的链接，先点右上角「…」→「在浏览器打开」，否则找不到下面要用的分享按钮。
  2. 点屏幕最下方正中间的「分享」按钮（一个方框，里面有一个向上的箭头）。
  3. 在弹出的菜单里往下滑，找到「添加到主屏幕」，点它。
  4. 右上角点「添加」。回到手机桌面，就多了一个「微信悦读」图标。

安卓（Chrome 或手机自带浏览器）

  1. 用浏览器打开 H5 页面。
    • 如果你是在微信里点开的，先点右上角「…」→「在浏览器打开」。
  2. 点右上角「⋮」（三个点的菜单）。
  3. 在菜单里选「添加到主屏幕」或「安装应用」（不同浏览器叫法略有差别）。
  4. 确认「添加 / 安装」。桌面就会出现图标。

在微信里打开是加不了的

微信内置浏览器不允许「添加到主屏幕」。所以要按上面第 1 步先「在浏览器打开」，再用系统浏览器（Safari / Chrome）来加。

三、微信小程序：加到手机桌面 / 我的小程序

小程序在微信里，加法也和浏览器不一样，而且安卓和 iPhone 不同：

安卓手机（华为 / 小米 / OPPO / vivo 等）

  1. 在微信里打开「悦读且住」小程序，点右上角「···」。
  2. 在弹出的菜单里选「添加到桌面」。
  3. 如果弹出权限提示，点「允许」。
  4. 回到手机桌面，就会出现「悦读且住」图标，以后点它就能直接打开。

菜单里找不到「添加到桌面」？

这一项要求小程序是正式发布版，且手机给了微信「创建桌面快捷方式」的权限。如果菜单里没有它：换一台安卓手机试试，或改用下面的「添加到我的小程序」。

iPhone / iPad

iPhone 不能把小程序的图标加到系统桌面，微信本身也不支持。替代做法是「添加到我的小程序」，一样方便：

  1. 在微信里打开「悦读且住」小程序，点右上角「…」。
  2. 选「添加到我的小程序」。
  3. 以后打开微信首页往下拉，顶部「我的小程序」里就有它，一键打开。

四、装完之后有什么好处

  • 图标一点就打开，不用记网址、不用翻书签；
  • H5 装到桌面后是独立窗口，没有浏览器的地址栏，和 App 几乎一样；电脑上则像装了一个软件；
  • 网页版本身不占内存、不用安装，不想用了直接删掉图标就行；
  • 小程序加到「我的小程序」后，在微信首页下拉即可打开。

常见问题

  • 桌面没看到图标？ 左右翻页找一下，或用桌面搜索「微信悦读 / 悦读且住」。
  • 电脑上地址栏没有「安装」图标？ 换 Chrome 或 Edge 打开；或点浏览器右上角「⋮」，在菜单里找「安装 微信悦读…」。
  • iPhone 上找不到「添加到桌面」？ iPhone 只支持把 H5 网页版加到桌面；小程序请用「添加到我的小程序」。
  • H5 加到桌面后打不开 / 显示的是旧内容？ 首次打开会缓存页面外壳，联网后会拉取最新数据；稍等或重新打开一次即可。
  • 想删掉图标？ 和删 App 一样，长按图标 → 移除 / 删除即可，不影响你的阅读数据。
