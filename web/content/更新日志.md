> [!note] 关于版本号
> 网站页脚显示的版本号、以及插件查询的「最新版本」，都直接读扩展的 `manifest.json`，不存在两处手写版本号的问题。

## v0.19.0 · 2026-10-04

「🧬 我的阅读人格」分享图新增「人物插画」。

- 16 型阅读人格各配一位**公共领域文化名人**：牛顿、达·芬奇、达尔文、阿基米德、康德、图灵、苏轼、李白、爱迪生、马克·吐温、李时珍、莫扎特、亚里士多德、蒙田、安徒生、莎士比亚
- 插画为本项目**自绘线描图**，随插件内置，**运行时不联网、不使用真人照片**（均为公共领域人物，非宗教、非政治）
- 分享图**顶部**新增人物插画（配人物名 + 呼应小字）；报告人格卡与 HTML / Markdown 导出也同步显示代表人物

## v0.18.0 · 2026-10-04

「☁️ 官方数据」新增「🧬 我的阅读人格」，并把分析与 AI 解读改为手动触发。

- 报告首屏新增「🧬 我的阅读人格」（读书人版）：读取你读得最多几本书（最多 5 本）的划线 / 想法，在本机做四维判定 + 16 型称号 + 词语分析，并可生成手机版分享图
- 「启用分析」与「AI 解读」改为**手动触发**：打开报告不再自动拉语料、不再自动调用 DeepSeek，点按钮才联网，更省请求与 token
- 修复书架 / 搜书 / 推荐里的跳转：点书名改为在新标签打开**网页版书籍详情页**（电脑可直接打开），不再跳只能手机打开的 App 链接

## v0.17.0 · 2026-10-04

「☁️ 官方数据」新增「📚 书架」与「🔍 发现」两个页签。

- 新增「📚 书架」：一眼看全书架（电子书 / 专辑 / 公众号数量汇总），分区列表展示封面、作者、阅读进度与来源，支持「显示更多」分页
- 新增「🔍 发现」：搜书（找书 / 泛搜 / 网文 / 听书 / 作者 / 全文 / 书单 / 公众号 / 文章多种范围，支持翻页）、推荐、公开书评（全部 / 推荐 / 不行 / 最新 / 一般，含星级与翻页）、相似书（含翻页）
- 书籍详情与目录：查看书籍基本信息与章节结构，封面、评分、阅读人数一目了然
- 所有书籍均可一键跳转微信读书 App（使用官方 `deepLink`，不自行拼接链接）

## v0.16.0 · 2026-10-04

「☁️ 官方数据」阅读行为报告补齐 V2「下半」，新增规律建议与笔记密度。

- 新增「十四、阅读规律与建议」：只用报告已有指标、按固定规则生成「事实句 + 温和建议」（时长节奏 / 阅读时段 / 偏好分类 / 完读率 / 笔记投入 / 书架规模），不编造数据、不下绝对化结论、不含健康建议；未配置 DeepSeek 时同样生成
- 「十、笔记行为」新增「10.2 笔记密度（衍生指标）」：平均每本笔记数、想法/点评占比、划线占比
- 自包含 HTML 导出（样式与图表脚本全内联、双击即看）沿用本轮图表能力

## v0.15.2 · 2026-10-04

「☁️ 官方数据」阅读行为报告新增原生图表可视化。

- 报告新增四类图表（纯原生 Canvas 绘制，零依赖）：折线（时长趋势）、横向条形（偏好分类权重）、热力格（24 小时阅读时段）、环形（完读率）
- 面板内与导出的 HTML 共用同一套绘制逻辑，导出自包含、双击即可查看

## v0.15.1 · 2026-10-04

维护性更新，功能与 v0.15.0 一致。

- 重新打包并提交商店版本，用于修复商店安装版的个别功能异常
- 本次未改动任何功能代码

## v0.15.0 · 2026-10-03

移除「主题设置」。

- 不再提供插件的明亮 / 暗黑 / 护眼主题切换与「使用官方主题」按钮。微信读书官方已自带主题切换，插件再做属于多余功能，故整体移除
- 其余功能（屏占比调节、自动阅读、快捷键、勿扰、全屏、阅读统计、笔记增强、官方数据）不受影响

## v0.14.1 · 2026-10-01

移除「点击笔记跳回原文」。

- 「📝 笔记」不再支持点条目跳转定位原文（翻页模式下无法可靠工作），仅保留面板内搜索定位；划线/想法聚合、一键复制、Markdown / 纯文本 / HTML / PDF 导出均不受影响

## v0.12.0 · 2026-09-29

笔记一键复制、官方数据报告升级为「深度画像」。

- 「📝 笔记」新增一键复制：富文本（可直接粘贴进文档）与 Markdown 两种；导出增加 HTML 与 PDF
- 「☁️ 官方数据」报告改为按深度画像组织：元信息 → 执行摘要 → 数据全景（核心指标 / 官方概要 / 偏好分类）→ 阅读轨迹与时间线 → 阅读时段分布 → 偏好画像（作者 / 出版社 / 版权方）→ 读得最多 → 书的印象 → 成就勋章 → 附录数据说明
- Markdown 与 HTML 导出共用同一份报告模型，避免两种格式内容漂移

## v0.11.0 · 2026-09-29

新增「官方数据」阅读行为报告。

- 新增「☁️ 官方数据」：粘贴自己的微信读书 `wrk-` Key，生成官方口径的阅读行为报告（总时长 / 阅读天数 / 自然日均 / 环比 + 时长分布 + 读得最多），支持本周 / 本月 / 本年 / 累计切换，可导出 Markdown / HTML / PDF
- 新增 `background.js` 与 `i.weread.qq.com` 主机权限：官方网关对带鉴权的跨域预检会失败，改由扩展身份请求，你的 Key 只发往官方网关

## v0.10.0 · 2026-09-29

- 新增「📝 笔记」：按章节聚合本书全部划线与想法；支持 Markdown / 纯文本批量导出
- 新增选中即复制：选中正文后弹出「📋 复制」，并自动清洗微信读书附加的版权声明

## v0.9.0 · 2026-09-29

- 新增「📊 阅读统计」：今日 / 本周 / 本月 / 本书时长，当前书籍进度与最近 10 本书
- 支持五种导出：JSON / CSV / Markdown / HTML 报表 / PDF
- 统计口径只计算页面在前台且停留在阅读页的时间；代码开始按 `modules/` 模块化组织

## v0.8.3 · 2026-09-29

- 修复：屏占比高时的透明感应层会挡住官方翻页点击区，改为按鼠标坐标判定，零遮挡
- 交互：悬浮球由「点击展开」改为「悬停即展开」，移开 250ms 收起
