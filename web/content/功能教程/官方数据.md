阅读统计是插件自己数的；「官方数据」拿的是**微信读书官方口径**的数字。

## 一、准备你自己的 Key

1. 打开微信读书 App → 「我」→ 微信读书 Skill 页
2. 生成一个 `wrk-` 开头的 API Key
3. 回到插件菜单 → 「🔑 API Key」→ 粘贴 `wrk-` Key 并保存（DeepSeek Key 也在这个入口填，可选）

> [!warning] Key 等于密码
> 它代表你本人的读取权限。只存在你浏览器的本地存储里，不会发给插件作者或任何第三方；请不要分享、不要提交到任何仓库。

## 二、看报告

保存 Key 后，打开菜单「☁️ 官方数据」，可以切换周期：**本周 / 本月 / 本年 / 累计**。

报告按「深度画像」组织，从概览一路落到细节：

| 章节 | 你会看到 |
|---|---|
| 执行摘要 | 这一周期最值得看的几个数字 |
| 数据全景 | 核心指标（总时长 / 阅读天数 / 自然日均 / 环比）、官方概要、偏好分类 |
| 阅读轨迹与时间线 | 这段时间的阅读节奏 |
| 阅读时段分布 | 你习惯在一天中的什么时候读 |
| 偏好画像 | 作者 / 出版社 / 版权方的集中度 |
| 读得最多 | 这个周期读得最多的书 |
| 书的印象 | 读过的书单印象 |
| 成就勋章 | 达标项 |
| 附录 | 数据口径说明 |

报告可以导出 Markdown / HTML / PDF。

## 三、数据流向（一句话）

你的 Key 和请求**只发往微信读书官方网关** `i.weread.qq.com`（和官方 App 的 Skill 用的是同一个服务），报告在你本机生成。插件没有自己的服务器。
