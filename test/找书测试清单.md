# 阶段十四 本地找书（v0.20.0） — 测试验收清单

> 前置：扩展管理页「重新加载」插件 → 打开 https://weread.qq.com（书架页或阅读页均可）→ 悬浮球展开主菜单 →「🔎 找书」。
> 排错统一看控制台 `[finder]` 开头日志。
>
> 说明：`modules/finder.js` 已用「模拟数据 + 真实浏览器」冒烟测试过三轮（首轮 8 项：面板渲染 / 打标签 / 标签筛选 / 状态筛选 / 关键词搜索 / 正文检索 / 标签重命名 / 无报错；补齐轮 5 项：封面图 / 进度条 / 拼音首字母 / 笔记区间 1-10 / 笔记区间 50+ 与无笔记；正文检索一键化轮 2 项：工具条「搜索正文」一键开启、空结果一键按钮命中划线，共 15 项全过，见下带 ✅ 标记项）。**其余带 `[ ]` 的条目需在真实账号 + 真实书架数据下实测。**

- [x] **1.2** 点击后弹出面板，标题为「🔎 找书」；再次点同一入口不重复叠加面板 ✅（冒烟）
- [x] **1.3** 面板顶部有一行「🔒 标签仅存本机…不上传、不写回微信读书」✅（冒烟）
- [x] **1.4** 有搜索框（placeholder「搜书名 / 作者 / 标签 / 拼音首字母…」）与「清空」按钮，下方有拼音首字母用法提示 ✅（冒烟）
- [x] **1.5** 三行筛选 chips：全部状态/在读/已读完/从未打开；笔记不限/无笔记/有笔记/1-10 条/11-50 条/50 条以上；时间不限/近 7 天/近 30 天/近 90 天/更早 ✅（冒烟）
- [x] **1.6** 工具条含：含划线/想法正文、搜索正文（有搜索词时）、刷新书架、导出 JSON、导入(合并)、导入(覆盖)、标签管理 ✅（冒烟）

- [ ] **1.8** **未配置** `wrk-` Key 时，面板显示「需要先配置官方 API Key」+「去配置 API Key」按钮；点击后关闭面板并打开「🔑 API Key」
- [ ] **1.9** 面板内点击遮罩空白处 / 右上角 `×` 均可关闭

## 二、书架数据加载

- [ ] **2.1** 首次打开：显示「正在读取书架…」后列出完整书架（电子书 + 专辑/有声书），条数与微信读书书架一致
- [ ] **2.2** 控制台出现 `[finder] 书架拉取成功` 与 `[finder] 笔记概览拉取成功`
- [ ] **2.3** 30 分钟内关闭再打开：底部提示「书架数据来自本机缓存（30 分钟内）」；点「刷新书架」后提示变为「刚刚拉取」
- [ ] **2.4** 断网 / Key 失效：面板给中文错误 + 「重试」按钮，不空白、不静默
- [ ] **2.5** 笔记接口单独失败：书架照常显示，仅在列表上方出现「⚠️ 笔记数本次未取到」提示，「有笔记 / 无笔记」筛选可能不准
- [ ] **2.6** 书架书目很多时（数百本）：列表默认渲染 150 本，底部出现「显示更多（还有 N 本）」，点击递增
- [x] **2.7** 每本书卡片左侧显示封面缩略图（无封面时显示 📖 占位）；书籍且有阅读进度时，标题下方显示绿色进度条 + 百分比 ✅（冒烟）

## 三、打标签

- [x] **3.1** 每本书卡片下方有「+ 加标签」输入框 ✅（冒烟）
- [x] **3.2** 输入标签名回车：该书出现带 `×` 的标签 chip，并弹出「已给《书名》加上标签「xx」」✅（冒烟）
- [ ] **3.3** 输入框聚焦时出现已有标签联想（datalist），选已有标签可避免同义标签分裂
- [ ] **3.4** 重复添加同一标签：不产生重复 chip
- [ ] **3.5** 点标签 chip 上的 `×`：标签移除；若该书标签清空，则不留下空壳（存储里该书条目被删除）
- [ ] **3.6** 关闭面板再打开、或刷新页面：标签仍在（已落 `chrome.storage.local`）
- [ ] **3.7** 标签名超长（>20 字）：自动截断为 20 字

## 四、多维度搜索 / 筛选

- [x] **4.1** 关键词搜书名 / 作者：列表实时过滤 ✅（冒烟，搜「认知」命中《认知觉醒》）
- [ ] **4.2** 关键词命中标签名：该书保留
- [ ] **4.3** 点状态「已读完」：只剩 `finishReading=1` 或进度 100% 的书；「从未打开」只剩无阅读记录的书 ✅（冒烟验证「已读完」）
- [x] **4.4** 点标签 chip 筛选：列表只剩挂该标签的书；点「清除已选(N)」恢复 ✅（冒烟）
- [ ] **4.5** 多标签 + AND：只保留同时命中全部所选标签的书；切到 OR：保留命中任一标签的书
- [x] **4.6** 笔记区间（无笔记 / 有笔记 / 1-10 条 / 11-50 条 / 50 条以上）：按「笔记数」列过滤，各区间不重叠、无遗漏（笔记数 = 划线 + 想法 + 书签）✅（冒烟，1-10 / 50+ / 无笔记 各命中 1 本）
- [ ] **4.7** 「近 7 天 / 近 30 天 / 近 90 天 / 更早」：按最近阅读时间过滤；从未打开的书不落入任何时间窗口
- [ ] **4.8** 组合筛选（如「已读完」+ 标签「认知科学」+ 关键词「简史」）：结果同时满足全部条件
- [x] **4.9** 「清空」按钮：搜索词清空、列表恢复全量 ✅（冒烟）
- [ ] **4.10** 中文输入法组词过程中：列表不闪烁、不打断输入，组词结束后才刷新
- [x] **4.11** 关键词为纯拼音字母时按「拼音首字母」模糊匹配（如 rzjx → 《认知觉醒》、rljs → 《人类简史》）✅（冒烟）

## 五、划线 / 想法正文检索

- [x] **5.1** 搜索框有词时，工具条直接出现「搜索正文」按钮；点它会**自动打开**「含划线/想法正文」开关并开始检索（一键，无需先点开关）✅（冒烟）
- [x] **5.2** 点了「搜索正文」：对有笔记的书逐本检索（4 本并发），工具条显示「正文检索中 x/y…」，命中书下显示「命中划线：…」/「命中想法：…」✅（冒烟，模拟数据）
- [x] **5.2b** 搜书名/作者搜不到、且还没开正文搜索时：结果区出现一键按钮「🔍 在划线/想法里搜「关键词」」，点击后自动开启开关并检索；命中后该书出现在结果里 ✅（冒烟）
- [ ] **5.3** 真实账号：能搜到「我确实在某本书里划过 / 记过的词」，且该书出现在结果里
- [ ] **5.4** 检索中改关键词 / 关闭「含划线/想法正文」/ 点「停止」：检索立即中断，不再继续拉取
- [ ] **5.5** 10 分钟内就同一关键词再次检索：命中内存缓存，明显更快（`[finder]` 无新拉取日志）
- [ ] **5.6** 手动关闭「含划线/想法正文」后：正文命中不参与筛选（仅按书名/作者/标签匹配）
- [ ] **5.7** 没有任何有笔记的书：提示「没有可检索的书…」，不报错
- [ ] **5.8** 数百本带笔记的书：检索有进度、可中断、界面不卡顿（每 10 本重绘一次）

## 六、标签管理

- [x] **6.1** 点「标签管理」展开：每个标签一行，显示标签名 + 书籍数 + 「重命名 / 合并… / 删除」✅（冒烟）
- [x] **6.2** 重命名：输入新名点「确定」，标签在管理区、筛选区、每本书上同步改名 ✅（冒烟）
- [ ] **6.3** 重命名成已存在的标签名：等价于合并，不产生重复标签
- [ ] **6.4** 合并：把「A」合并到「B」，所有挂 A 的书改为 B，A 消失，B 的书籍数增加
- [ ] **6.5** 删除：标签从所有书移除（书不删）；若某书标签因此清空，则其条目消失
- [ ] **6.6** 重命名 / 合并 / 删除后刷新页面：结果保持（已落盘）

## 七、导出 / 导入（防丢）

- [ ] **7.1** 点「导出 JSON」：下载 `微信悦读-找书标签-YYYYMMDD.json`，内含 `app/kind/schemaVersion/exportedAt/tags`，`tags` 为 `{书ID: {title, author, tags[]}}`
- [ ] **7.2** 没有任何标签时点「导出 JSON」：提示「还没有任何标签可以导出」，不生成文件

- [ ] **7.4** 「导入(覆盖)」选同一份 JSON：清空后写入；提示「已覆盖导入：…」
- [ ] **7.5** 选一个非法文件（非本插件 JSON / 坏 JSON）：提示中文错误，标签不变更，不崩溃
- [ ] **7.6** 导入后：筛选区、每本书的标签、标签管理全部同步更新
- [ ] **7.7** 「导出 → 清掉本地标签（可在扩展存储里清）→ 导入(覆盖)」：标签完整还原
