## 插件装了但页面上没有反应

**先确认这三件事：**

1. 你打开的是 https://weread.qq.com（插件只在微信读书网页版生效，其他网站不会出现）
2. 打开的是**阅读页**（一本书的正文页），书架首页不会显示悬浮球
3. 扩展已启用（`edge://extensions/` 里微信悦读是开启状态）

都正常还不出现的话，刷新一次页面。

## 屏占比拉高了，翻页按钮不见了

这是预期行为：正文变宽后，按钮会改为浮动显示。把鼠标移到**屏幕顶部边缘**或**右侧边缘**，工具栏会自动淡入；移开就淡出。

## 主题切换后画面不对

- 先换回「明亮」再切到目标主题，排除上一次切换没走完
- 图片、封面也会跟着主题变化，这是正常现象
- 如果正文长时间不正常，刷新页面

## 阅读统计一直是 0

统计只记录**页面在前台、且停留在阅读页**的时间：

- 切到别的标签页、最小化窗口 → 不计时
- 停在书架、书城页面 → 不计时
- 打开一本书读一会儿再看，数字就出来了

## 快捷键按了没反应

- 先点一下正文区域（让页面获得焦点）再按
- `?` 在中文输入法组词状态下也能用（已按物理键识别）
- 确认没有和浏览器／系统的其他快捷键冲突

## 官方数据拉不到 / 提示 Key 无效

- Key 必须是微信读书 App「微信读书 Skill」页生成的 `wrk-` 开头字符串
- 复制时注意别带上空格或换行
- Key 有有效期，失效后重新生成一个再粘贴
- 网络异常时会失败，稍后重试；插件不会因此弹窗打扰你

## 换电脑后设置没了

设置保存在**当前浏览器本地**，不会跟着账号同步。换设备需要重新设一次。
