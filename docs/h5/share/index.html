朗读与分享

朗读：把内容听出来

H5 的朗读默认用云端神经语音（音色自然、接近真人），只在你点击朗读时，把待读的文本发到我们的中转服务实时合成音频、回传后在本机播放——音频不落盘、不保存文本。若合成不可用（网络不通等），会自动改用浏览器本机的语音兜底，你不用管。

支持朗读的页面：

  • 每日卡片：「🔊 朗读这张卡片」
  • 灵感漫游：「🔊 朗读这一期」
  • 阅读人格：「🔊 朗读人格」

怎么控制： 页面底部的控制条可以「上一条 / 暂停·继续 / 下一条 / 停止」，长文本会被自动分段朗读。

切到后台就停

朗读不会在后台常驻——你切走或锁屏，它就自动停止。两种语音都不可用时，按钮会隐藏。

分享图：竖版图，一键发出去

在 阅读人格 / 每日卡片 / 灵感漫游 三处可以生成竖版 PNG 分享图（宽 1080，高度随内容自适应，纯文字排版，不含账号信息）。

生成后按顺序尝试三种方式：

  1. 分享：手机支持系统分享时，直接分享到微信等 App；
  2. 保存图片：不支持系统分享时，下载 PNG 到相册 / 下载目录；
  3. 复制链接：另有复制链接的兜底方式。

添加到主屏幕（像 App 一样用）

H5 支持「添加到主屏幕」（PWA）：iPhone / Safari 用底部分享按钮 → 「添加到主屏幕」；Android / Chrome 用右上角菜单 → 「添加到主屏幕 / 安装应用」。

加完之后从桌面图标打开，就是一个独立窗口，没有浏览器的地址栏，用起来和 App 几乎一样。完整分步教程（含微信内打开、小程序怎么做）见 加到手机桌面。

断网时能打开，但看不到新数据

页面外壳会被缓存，断网也能打开；但阅读数据、AI 都要联网获取，所以断网时看到的是上次缓存的框架，不是最新数据。
