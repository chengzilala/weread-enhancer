## 二、小程序类目

> 位置：后台 **设置 → 基本设置 → 服务类目**。个人主体可选类目有限，**以后台可选列表为准**；本工具属「数据展示/效率工具」，按下面顺序找：

| 顺位 | 建议类目 | 说明 |
|---|---|---|
| ⭐ 首选 | `工具 → 效率` | 个人主体通常可开通，最匹配「阅读数据报告工具」定位 |
| 备选 1 | `工具 → 信息查询` | 若「效率」不可选，退而选它 |
| 备选 2 | `教育 → 教育信息服务` | 部分个人主体可开；偏「阅读/学习」时会用到 |

**注意：**
- 只需勾选**真正会用到**的类目，**类目越少审核越简单**；把主营类目设为上表首选。
- 「图书/阅读/资讯」等类目通常**需要资质或企业主体**，个人一般不可选；不可选时**一律选工具类**，不要硬凑。
- 提交后若被要求补充资质，**改回工具类**即可，不影响功能。

## 三、添加开发者

> 位置：后台 **管理 → 成员管理 → 项目成员 → 添加**。

**步骤：**
1. 选择成员类型 **「项目成员」**（不是体验成员）。
2. 输入对方**微信号**（或已关注的微信号），设置权限后保存。
3. 对方在微信里**确认邀请**即可。
4. 权限按需给：

| 权限 | 能做什么 | 建议 |
|---|---|---|
| 开发者（开发管理） | 用开发者工具开发、上传代码；**不能**提交审核/发布 | 开发协作时给 |
| 运营者 | 管理运营、发布相关 | 只给最信任的人 |
| 数据分析者 | 只看数据统计 | 一般不需要 |
| 体验成员（另一分组） | 只能扫码用「体验版」，不能上传代码 | 只做测试时加这个 |

**可直接转发的邀请话术：**

```text
我在做一个微信小程序「悦读且住」，想请你帮忙一起看下：
1. 你把微信号发我，我在小程序后台把你加成「项目成员」；
2. 你去微信里点确认邀请；
3. 之后你也能用微信开发者工具打开这个项目调试。
提醒：只有管理员能提交审核和发布，其他人只能开发和上传代码。
```
