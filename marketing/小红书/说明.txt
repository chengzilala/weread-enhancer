【怎么发】
  推荐：仓库根目录执行
        python3 tools/xhs_publish.py                      # 发「综合全面版」（16 张图）
        python3 tools/xhs_publish.py --list               # 列出全部可发篇目（A/B/C/D/E/F 分类）
        python3 tools/xhs_publish.py --list A             # 只看 A 破圈类
        python3 tools/xhs_publish.py --post A1            # 按编号发扩展篇（自动只传该篇配图）
        python3 tools/xhs_publish.py --post F1            # 发「心路/品牌层」F1（原文照录）
        python3 tools/xhs_publish.py --post "篇 1"        # 发系列分篇
        python3 tools/xhs_publish.py --post A1 --dry      # 只打印将发的内容，不操作
  脚本会打开小红书创作平台 → 你扫码登录 → 自动上传配图并填好标题/正文/话题 →
  停在「发布」按钮前，你核对后自己点「发布」。每天发哪篇、几点发，见「小红书运营计划.md」第四节「逐日排期表」。

  手动：小红书 App / 网页版「发布笔记」→ 上传图文 → 打开该帖的「帖子/<编号>-<短标题>/」
        文件夹，按 01- / 02- 序号依次选图（第一张即封面）→
        标题与正文见「小红书文案.md」（综合全面版 §2；系列分篇 §3；扩展笔记池 §3.5）→ 话题照抄该段末尾一行。

  ★ 每帖正文末尾只带一句**软引导**（如「想要的话评论区吱一声，或者私信我～」）——
    小红书判「站外引导」极严（域名 / 商店搜 / 微信搜 / 其他平台名都会被判限流），
    正文 / 评论 / 主页**一律不写站外信息**；完整入口只在**私信**里 1 对 1 发给来问的人。
    发布后立刻发第一条评论（**软引导、不放链接**）并置顶，模板见「小红书文案.md」第 0 节。

【口径红线】
  · 只讲已实现功能、不夸大；不承诺「永久免费 / 绝对无广告」。
  · 正文 / 评论 / 主页**一律不写站外信息**（域名 / "搜 XXX" / 其他平台名）；正文只留软引导，完整入口只走私信。
  · 快捷键仅 空格 / D / F / ?（不写 T）。
  · 语音一律「朗读 / 听」；大模型只列 6 家国产。
  · 隐私只说「不上传你的阅读数据」。
  · 小程序：小红书**不带"微信搜"、正文不放**（只私信给）；其它渠道每帖底部带（未上线也写）。
  · 以上对 F 类例外：F 类为作者本人原文照录（含 https:// 完整链接、
    小程序入口、「永久免费」类表述、Claude 工具名），按「原味保留」要求一字不改。
