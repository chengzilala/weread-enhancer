阅读洞察：阅读行为报告 · 书架 · 发现

阅读统计是插件自己数的；「阅读洞察」拿的是微信读书官方口径的数字。

一、准备你自己的 Key

  1. 打开微信读书 App → 「我」→ 微信读书 Skill 页
  2. 生成一个 wrk- 开头的 API Key
  3. 回到插件菜单 → 「🔑 API Key」→ 粘贴 wrk- Key 并保存（DeepSeek Key 也在这个入口填，可选）

Key 等于密码

它代表你本人的读取权限。只存在你浏览器的本地存储里，不会发给插件作者或任何第三方；请不要分享、不要提交到任何仓库。

二、三个页签

配好 Key 后，打开菜单「🪞 阅读洞察」，面板顶部有三个页签：📊 阅读行为报告 / 📚 书架 / 🔍 发现。

📊 阅读行为报告

可以切换周期：本周 / 本月 / 本年 / 累计。报告按「深度画像」组织，从概览一路落到细节：

章节你会看到
一、执行摘要这一周期最值得看的几个数字（配置 DeepSeek 后为 AI 人格化解读）
二、数据全景2.1 核心指标（总时长 / 阅读天数 / 自然日均 / 环比）、2.2 书架结构、2.3 官方概要、2.4 偏好分类
三、阅读轨迹与时间线这段时间的阅读节奏（折线图）
四、阅读时段分布你习惯在一天中的什么时候读（热力格，仅「累计」周期）
五、偏好画像偏好作者 / 出版社 / 版权方
六、读得最多这个周期读得最多的书
七、书的印象官方按书架语义挑出的分类代表书
八、成就勋章达标项（仅「累计」周期）
九、知识脉络书架分类分布
十、笔记行为10.1 概览、10.2 笔记密度、10.3 笔记最多的书
十一、完读率电子书读完比例（环形图）
十二、已读完书目已读完的电子书清单
十三、阅读人格画像按客观指标归类出的类型标签
十四、阅读规律与建议按固定规则生成的「事实句 + 温和建议」
十五、阅读人格（读书人版）4 位人格代码 + 主称号（16 型读书人）+ 词语分析（详见 阅读人格）
附录数据口径说明

报告里还会画几张原生图表（零依赖绘制）：折线（时长趋势）、横向条形（偏好分类权重）、热力格（24 小时阅读时段）、环形（完读率）。报告可以导出 Markdown / HTML / PDF；导出的 HTML 是自包含的，双击就能打开。

📚 书架

一眼看全书架：电子书 / 专辑 / 公众号的数量汇总，下面按分区列出每本书的封面、作者、阅读进度与来源。书多时点「显示更多」分页展开，点「刷新」重新拉取。

🔍 发现

「发现」里有两个子页签：

  • 🔍 搜书：输入书名 / 作者 / 关键词，可选范围（找书 / 泛搜 / 网文 / 听书 / 作者 / 全文 / 书单 / 公众号 / 文章），结果多时「加载更多」翻页
  • ✨ 推荐：点「获取推荐」拿一批推荐书（含推荐理由），可「加载更多」

每本书右侧有三个按钮：

按钮作用
详情 / 目录看这本书的基本信息与章节结构
书评看公开书评，可切换 全部 / 推荐 / 不行 / 最新 / 一般，评分显示为 1~5 星，可「加载更多书评」
相似书找和这本书相似的书，可「加载更多」

跳转（电脑也能打开）

点书名或条目会在新标签打开网页版书籍详情页（weread.qq.com），电脑上直接就能看。插件不自行拼接链接：官方返回的是 App 专用地址（电脑打不开），会按书名换成网页版链接再打开。

三、数据流向（一句话）

你的 Key 和请求只发往微信读书官方网关 i.weread.qq.com（和官方 App 的 Skill 用的是同一个服务），报告在你本机生成。插件没有自己的服务器。
