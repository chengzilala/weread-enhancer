# 阶段十三 V1 官方数据（v0.11.0） — 测试验收清单

> 前置：扩展管理页 `edge://extensions/` →「重新加载」插件（本次改了 manifest：新增 service worker 与 `i.weread.qq.com` 主机权限，**必须重载**）→ 打开 weread.qq.com → 悬浮球展开主菜单。
> 排错统一看控制台：内容脚本日志前缀 `[official]`，后台日志前缀 `[official][bg]`（后台日志在「扩展详情 → Service Worker → 检查」里看）。
> 未配置 Key 时，除第 3、4 组外大部分用例需先完成 3.1。

## 二、未配置 Key 的初始态

## 三、Key 设置（保存 / 校验 / 显示 / 清除）

- [ ] **3.1** 粘贴自己的 `wrk-` Key → 点「保存并校验」→ 提示「保存成功，Key 已通过校验」，输入框自动清空
- [ ] **3.2** 输入框默认掩码显示（`type=password`）；点「显示」变明文、按钮文字变「隐藏」，再点变回
- [ ] **3.3** Key 前后带空格：粘贴后直接保存，能校验成功（已自动 trim）
- [ ] **3.4** 空输入点「保存并校验」：提示「请先粘贴 API Key」，不发起请求
- [ ] **3.5** 输入不以 `wrk-` 开头的串（如 `abc123`）点保存：提示「Key 格式不对：应以 wrk- 开头」，不发起请求
- [ ] **3.6** 输入错误的 `wrk-` Key 点保存：提示「API Key 无效或已失效，请在「设置」里重新填写」，**不写入** storage
- [ ] **3.7** 点「清除 Key」：弹确认框；确认后提示「已清除 Key」，状态行变「未配置」
- [ ] **3.8** 清除确认框点「取消」：Key 保持不变，状态仍为「已配置」
- [ ] **3.9** 点「刷新状态」：状态行更新（含保存时间 / 最近校验时间 / `skill_version`）
- [ ] **3.10** 换一个新 Key 保存成功后，旧报告缓存被清除（回报告页会重新拉取，不是旧数据）
- [ ] **3.11** 设置页显示安全提醒（Key 等同账号读取权限，勿外传 / 怀疑泄露可重置）
- [ ] **3.12** **重点**：保存 / 校验 / 清除过程中，控制台 `[official][bg]` 日志里**只出现掩码**（形如 `wrk-****(24)`），**绝不出现完整 Key**

## 十、数据口径已知结论（用于对照，非勾选项）

- 官方所有时长字段单位是**秒**。
- 分桶时间戳是**「中国时区零点」编码成的 UTC 秒**（实测 `mod 86400 = 57600`），展示必须 +8h；直接按 UTC 会差一天/一年。
- 环比 `compare` **仅当前周期**返回；累计不返回 `dayAverageReadTime`。
- `readLongest` 官方已过滤低于约 5 分钟的内容。
- 本功能数据全部来自**官方 gateway**，与「📊 阅读统计」的**本地口径估算**是两套独立数据，不合并、不互相覆盖。
