# 悦读且住 · 移动端（微信小程序）

只做「读完之后」的复盘与分享：阅读总览、阅读人格、阅读行为报告、书架。不包含屏占比 / 勿扰 / 自动阅读等桌面阅读增强功能。

- 需求文档：[../plan/RPD_小程序移动端_需求文档.md](../plan/RPD_小程序移动端_需求文档.md)
- 开发计划：[../plan/plan_小程序移动端.md](../plan/plan_小程序移动端.md)

## 目录结构

```
mobile/
├── project.config.json          # 开发者工具项目配置（miniprogramRoot / cloudfunctionRoot）
├── miniprogram/                 # 小程序前端
│   ├── app.js / app.json / app.wxss
│   ├── config.js                # 云开发环境 ID（需你填写）
│   ├── shared/                  # 公共模块：本地存储 / 网关调用 / 错误文案 / 格式化 / 报告与人格计算 / 人格线描与分享图 / 云同步 / AI 画像
│   ├── components/              # 公共组件：wre-state（加载骨架 / 空态 / 错误态 / 无 Key 引导）
│   └── pages/                   # home 首页 · persona 人格 · report 报告 · shelf 书架 · settings 我的 · notes 笔记概览
├── cloudfunctions/
│   └── wereadProxy/             # 云函数：① 官方网关中转（绕过 CORS）② 人格结果云同步 ③ DeepSeek AI 转发
└── 素材/                        # 小程序头像等上架素材
```

## 第一次运行（零基础照做）

### 1. 准备
- 安装「微信开发者工具」（稳定版）。
- 有一个已注册的微信小程序账号（个人主体即可）。

### 2. 导入项目
1. 打开微信开发者工具 → 「导入项目」。
2. 目录选择本文件夹 `mobile/`（含 `project.config.json` 的那层）。
3. AppID 选择你自己的小程序 AppID。

### 3. 开通云开发
1. 开发者工具顶部点「云开发」→ 按引导开通（首次会创建环境）。
2. 记下环境 ID（形如 `cloud1-1a2b3c4d`）。
3. 打开 `miniprogram/config.js`，把 `CLOUD_ENV` 填成这个环境 ID（不填也能跑，但推荐填写，避免选错环境）。

### 4. 部署云函数
1. 在开发者工具左侧文件树找到 `cloudfunctions/wereadProxy`。
2. 右键 → 「上传并部署：云端安装依赖」。
3. 等右下角提示部署成功。
4. **改超时时间（重要）**：打开「云开发控制台 → 云函数 → wereadProxy → 配置」，把「超时时间」从默认 3 秒改为 **30 秒**。默认 3 秒会在网关请求返回前就中断（AI 转发最长用 30 秒），前端会报「云函数调用失败」。
5. **建云同步集合（人格结果云同步需要）**：打开「云开发控制台 → 数据库 → 新建集合」，集合名填 `wre_sync`，权限选「**仅创建者可读写**」。（函数也会尝试自动创建，但手动建更稳妥。）

### 5. 使用
1. 编译运行小程序 → 底部「我的」。
2. 粘贴你的 `wrk-` 开头的 API Key（微信读书 App →「微信读书 Skill」页面复制）。
3. 点「保存并校验」→ 通过后回「首页」。
4. 「人格」页可点「生成竖版分享图」→ 预览 → 保存到相册（弹层内长按图片也可转发）；进入时会先从云端读取上次结果「秒显」，并在算完后静默上传。
5. （可选）在「我的」页设置头像昵称（仅存本机，用于分享图署名）；填入 DeepSeek Key 后，可在「人格」页点「生成 AI 画像」。

### 6. 增量部署（之前已跑过旧版时）

阶段 2.5 / 2.6 之后，若你早已部署过，本次只需补做这 4 件（其余不用重来）：

1. **重新部署云函数**：右键 `cloudfunctions/wereadProxy` →「上传并部署：云端安装依赖」。
2. **改超时**：云开发控制台 → 云函数 → `wereadProxy` → 配置 → 超时时间 **30 秒**。
3. **建集合**：云开发控制台 → 数据库 → 新建集合 `wre_sync`（权限「仅创建者可读写」）。
4. **配隐私声明**：小程序后台《用户隐私保护指引》勾选「**昵称、头像**」「**相册（仅写入）**」，并补充 openid 云同步 / AI 外发说明（文案见 [发布前准备 §五](../plan/小程序_发布前准备.md)）。不勾选会导致「选择头像 / 保存到相册」在真机被拦截。

> 注：`miniprogram/config.js` 的 `CLOUD_ENV` 必须与「当前环境」一致，否则前端连不到你部署的云函数。

## 验证方式
完整的真机验收 / 回归清单见 [test/移动端小程序测试清单.md](../test/移动端小程序测试清单.md)（覆盖 Key 管理、首页、报告、人格、书架、笔记、分享图、合规、B 类延展）。

### 快速冒烟（模拟器 5 分钟）
1. 「我的」页填 `wrk-` Key → 保存并校验通过 → 重开小程序无需再输。
2. 首页 / 报告 / 人格 / 书架 能出数据，不卡在加载；未填 Key 时各页显示引导不报错。
3. 人格页 → 生成竖版分享图 → 预览正常（真机再点「保存到相册」）。
4. 人格页生成结果后，云开发控制台 `wre_sync` 出现一条文档（不含任何 Key）。
5. 开发者工具「清缓存 → 全部清除」→ 重进人格页 → 应**先秒显**人格，而非先转圈（云同步生效）。
6. （可选）「我的」页填 `sk-` DeepSeek Key → 人格页「生成 AI 画像」出两段文字。

最基础先过这几条（阶段 0）：
- [ ] 「我的」页能保存并校验 `wrk-` Key，重开小程序无需再输。
- [ ] 未配置 Key 时，首页 / 人格 / 报告 / 书架 / 笔记显示引导，不报错。
- [ ] Key 格式不对（非 `wrk-` 开头）时前端直接拦截并提示。
- [ ] Key 失效时提示「API Key 无效或已失效」。
- [ ] 「清除 Key」后，各页回到引导态。

> 首页 / 报告 / 人格 / 书架 / 笔记均已实现；人格页可生成竖版分享图并保存到相册。

## 说明
- API Key（`wrk-` 微信读书 / `sk-` DeepSeek）只存手机本地（`wx.setStorageSync`），不登录、不绑定微信账号。
- 数据请求经云函数 `wereadProxy` 内存中转，中转不存储、不记录 Key（日志仅掩码）。
- 人格结果云同步：云函数用 `getWXContext().OPENID` 取用户标识，按 openid 隔离只存「人格结果」，不存 Key、不存官方原始数据；未开通云开发时自动跳过，不影响本机使用。
- 头像昵称（可选）仅存本机，仅用于「我的」页展示与分享图署名，不上传。
