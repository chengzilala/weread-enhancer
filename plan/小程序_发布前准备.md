## 二、小程序类目

> 位置：后台 **设置 → 基本设置 → 服务类目**。个人主体可选类目有限，**以后台可选列表为准**；本工具属「数据展示/效率工具」，按下面顺序找：

| 顺位 | 建议类目 | 说明 |
|---|---|---|
| ⭐ 首选 | `工具 → 效率` | 个人主体通常可开通，最匹配「阅读数据报告工具」定位 |
| 备选 1 | `工具 → 信息查询` | 若「效率」不可选，退而选它 |
| 备选 2 | `教育 → 教育信息服务` | 部分个人主体可开；偏「阅读/学习」时会用到 |

**注意：**
- 只需勾选**真正会用到**的类目，**类目越少审核越简单**；把主营类目设为上表首选。
- 「图书/阅读/资讯」等类目通常**需要资质或企业主体**，个人一般不可选；不可选时**一律选工具类**，不要硬凑。
- 提交后若被要求补充资质，**改回工具类**即可，不影响功能。

### 2.1 类目与资质确认记录（个人主体口径）

> 结论（2026-10-05 核对）：**个人主体走「工具类」是安全区，无资质缺口**，与本小程序定位一致。

- **可开 / 无资质要求**：`工具` 下多数细分类目（效率、信息查询、图片/音视频处理、记账等）个人主体通常可开通，纯工具、非经营定位**无需额外资质**。
- **需规避（个人主体通常不可选 / 需资质或企业主体）**：金融、医疗健康、新闻资讯、社交、电商、直播，以及 **AI 生成内容**类等。
- **本小程序定性**：**阅读数据展示工具**，不提供内容发布、交易、社交。主体功能全部为本机规则计算；仅「AI 人格画像」为可选增强，需用户自填自己的 DeepSeek Key 并主动点击才触发（不构成平台意义上的「AI 生成内容」服务，也不内置我方模型能力）——**不触碰上述受限类目**。
- **落地动作**：后台 `设置 → 基本设置 → 服务类目` 首选 `工具 → 效率`；以后台实际可选项为准，按上表顺位回退。
- **风险**：无。若审核误判为「阅读/资讯」，用 §六 备注澄清为「个人阅读数据展示工具」即可。

## 三、添加开发者

> 位置：后台 **管理 → 成员管理 → 项目成员 → 添加**。

**步骤：**
1. 选择成员类型 **「项目成员」**（不是体验成员）。
2. 输入对方**微信号**（或已关注的微信号），设置权限后保存。
3. 对方在微信里**确认邀请**即可。
4. 权限按需给：

| 权限 | 能做什么 | 建议 |
|---|---|---|
| 开发者（开发管理） | 用开发者工具开发、上传代码；**不能**提交审核/发布 | 开发协作时给 |
| 运营者 | 管理运营、发布相关 | 只给最信任的人 |
| 数据分析者 | 只看数据统计 | 一般不需要 |
| 体验成员（另一分组） | 只能扫码用「体验版」，不能上传代码 | 只做测试时加这个 |

**可直接转发的邀请话术：**

```text
我在做一个微信小程序「悦读且住」，想请你帮忙一起看下：
1. 你把微信号发我，我在小程序后台把你加成「项目成员」；
2. 你去微信里点确认邀请；
3. 之后你也能用微信开发者工具打开这个项目调试。
提醒：只有管理员能提交审核和发布，其他人只能开发和上传代码。
```

## 五、用户隐私保护指引（可直接照填）

> **位置**：**首次发布（未上线）时后台通常没有该入口**，走 **提审页面底部「用户隐私保护指引设置」**（选「采集用户隐私」后填写）；上线后可在 **mp 后台 → 左下角头像 → 账号设置 → 服务内容声明 → 用户隐私保护指引** 修改。以后台实际出现的选项为准。

### 5.1 需要勾选 / 声明的信息（对照后台选项）

后台「用户隐私保护指引」会按小程序实际调用的隐私接口展示**必填项**，本小程序涉及以下两项：

| 后台信息类型 | 触发来源（代码） | 用途说明（可直接粘贴） |
|---|---|---|
| **昵称、头像** | `<button open-type="chooseAvatar">`、`<input type="nickname">`（「我的」页 · 我的资料，**可选功能**） | 用于在「我的」页展示你的头像昵称，并在生成的分享图上署名；仅保存在你的手机本地，不上传服务器、不向第三方共享 |
| **相册（仅写入）** | `wx.saveImageToPhotosAlbum`（人格页 · 保存分享图到相册） | 仅在你点击「保存到相册」时把图片写入相册，不读取你的相册内容 |

> 若后台未自动列出上述项，请**手动勾选**；未声明对应项将导致组件/接口被禁用（头像昵称选择、保存相册都会失败）。

### 5.2 需要「补充说明」的信息（写进自定义 /「其他」项）

下面两项不产生平台隐私接口调用，但涉及数据上云 / 外发，需在指引中如实补充：

```text
① 云同步（用户标识）：为让你换设备后仍能快速看到此前算出的「阅读人格」，
本小程序在使用人格功能时，会通过微信云开发获取你的用户标识（openid），
并把「阅读人格结果」（不含阅读原文、不含任何 API Key）按该标识隔离存储于微信云开发数据库；
你可在「我的」页清除本机数据，或通过下方联系方式要求删除云端记录。

② AI 人格画像（用户主动触发）：当你在人格页主动点击「生成 AI 画像」时，
本小程序会将该人格的「判定结果与证据」（阅读统计、四维判定、用于佐证的划线摘录）
发送至第三方大模型服务 DeepSeek（深度求索）用于生成文字；
不发送你的微信身份、手机号或任何 API Key。你可选择不使用该功能，不影响其它功能。
```

### 5.3 关于「API Key」与云函数（如审核需要解释，用这段）

你粘贴的**微信读书 API Key**（以及可选的 **DeepSeek API Key**）均由你本人主动提供：

- 两者**只保存在你的手机本地**（微信本地缓存），卸载小程序或清理缓存即丢失；
- 调用时经**微信云函数内存中转**访问对应官方接口，**不落库、不记录**（服务端日志仅出现掩码，如 `wrk-****(44)`）；
- 随时可在「我的」页清除。

> 口径：这不属于平台隐私接口所采集的个人信息，**无需勾选采集项**。

**如被要求补充采集项（备选文案，信息类型选「其他」）：**

```text
信息类型：其他
收集的信息：用户主动填写的第三方服务凭证（微信读书 API Key；可选 DeepSeek API Key）
使用目的：以用户本人身份调用微信读书官方接口读取其阅读数据，在本机生成阅读报告与阅读人格；或经用户自填的 DeepSeek Key 生成 AI 人格画像
存储与共享：仅存储于用户设备本地；不在服务器存储或留存，不向任何第三方共享（DeepSeek Key 仅在用户主动生成时经云函数内存转发）
删除方式：在小程序「我的」页随时清除
```
