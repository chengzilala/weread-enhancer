# 软件著作权（软著）申请材料

> **放什么**：申请中国版权保护中心「计算机软件著作权登记」所需的**材料与生成器**。
> **不放什么**：对外推广文案在 `marketing/` 各渠道目录；本目录只服务「软著登记」这一件事。

---

## 一、这个目录解决什么

把「准备材料」这一步自动化：跑一个脚本，**直接生成两份可直接打印/提交的材料**——

| 产物 | 说明 | 软著要求 |
|---|---|---|
| `输出/源程序-*.pdf` | 从扩展源码自动抽取 | **前 30 页 + 后 30 页**，每页**≥50 行**，页眉含软件名+版本、页脚含页码 |
| `输出/用户操作手册-*-提交版(前30+后30).pdf` | 由站内教程整合，**这是要提交的那份** | 图文手册：封面 + 目录 + 分章 + 19 张功能截图 |
| `输出/用户操作手册-*.pdf` | 手册**完整版**（113 页，供你自己翻阅，不用提交） | — |

PDF 由脚本调用本机 Chrome 自动生成；同目录的 HTML 源文件也保留，浏览器打开 → `Cmd/Ctrl + P` → 「另存为 PDF」也能手工导出。

---

## 二、怎么生成

在**项目根目录**执行：

```bash
python3 marketing/软著申请/gen_materials.py --pdf     # 一步到位：出 HTML + PDF + 手册提交版（推荐）
python3 marketing/软著申请/gen_materials.py           # 只出 HTML（想自己打印时用）
```

生成物在 [输出/](./输出/)。**直接拿这两份 PDF 去提交即可**：

| 提交用文件 | 页数 |
|---|---|
| `源程序-…-V1.0.pdf` | **60 页**（前 30 + 后 30） |
| `用户操作手册-…-提交版(前30+后30).pdf` | **60 页**（前 30 + 后 30） |

> 改了软件名/作者后重跑，两份 PDF 会一并刷新。
> 打印校验：纸张 **A4**、边距**默认**、缩放 **100%**。

## 三、提交前必须准备的 4 样材料

| # | 材料 | 从哪里来 |
|---|---|---|
| 1 | **登记申请表** | 版权中心系统在线填写，自动生成，不用手写 |
| 2 | **源程序**（前30+后30页） | `输出/源程序-*.html` → 打印成 PDF |
| 3 | **软件文档**（用户手册） | `输出/用户操作手册-*.html` → 打印成 PDF |
| 4 | **身份证明** | 个人：身份证正反面扫描件（清晰、四角完整） |

---

## 四、⚠️ 两个关键点（务必先改）

1. **软件名称不能含「微信」**（腾讯商标，会被要求授权或驳回）。
   默认已用中性名 **《悦读浏览器阅读增强扩展软件》**。
   想改名：编辑 [gen_materials.py](./gen_materials.py) 顶部的 `SOFTWARE_NAME`，重新运行即可。

2. **著作权人填真实姓名**。
   脚本顶部 `AUTHOR` 默认是 GitHub 账号 `chengzilala`，**提交前请改成身份证上的真实姓名**（个人申请）。

## 五、提交入口与周期

- 入口：中国版权保护中心 https://www.ccopyright.com.cn （「软件著作权登记系统」）
- 费用：**官方 0 元**（中介代办才收费）
- 周期：约 **30–60 个工作日**
- 流程：注册账号 → 实名认证 → 在线填表 → 上传/邮寄材料 → 等审核 → 领证

---

## 六、常见被驳回原因（避开就顺）

| 原因 | 对策 |
|---|---|
| 名称含「微信」 | 已用中性名，勿改回 |
| 源程序每页不足 50 行 | 脚本已按 50 行/页分页，勿手动删行 |
| 页眉页脚缺软件名/版本/页码 | 脚本已自动加 |
| 源程序夹杂大量空行 | 抽取的是源码正文，正常 |
| 文档太薄、看不出功能 | 手册已整合全部功能教程 |
