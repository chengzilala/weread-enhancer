微信读书本身不告诉你「我到底读了多少」。这个面板补上这一块。

## 看什么

- **时长**：今日 / 本周 / 本月 / 本书
- **当前书籍进度**：书名、进度百分比、章节与阅读位置
- **最近阅读**：最近 10 本，点一下直接跳回那本书

统计口径是**只看你真正在读书的时间**：页面在前台、且停留在阅读页才算；切到别的标签页就停表。所以数字比「开着页面挂一天」要诚实。

## 导出

五种格式，按用途选：

| 格式 | 用途 |
|---|---|
| Markdown | 贴进 Obsidian / 笔记软件 |
| CSV | 丢进表格软件自己算 |
| JSON | 结构化全量数据，给程序用 |
| HTML 报表 | 单文件、可直接分享 |
| PDF | 浏览器打印另存，用来存档 |
