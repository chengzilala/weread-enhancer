# 阅读页评论侧栏（v0.28.0） — 测试验收清单

> 前置：扩展管理页「重新加载」插件 → 登录微信读书 → 打开某本书的阅读页（`weread.qq.com/web/reader/…`）。
> 排错统一看控制台 `[reviews]` 开头日志（同源接口、复用登录 Cookie，**免 Key、免新增权限**）。
> 说明：本模块展示**他人公开评论**（只读）；「📝 笔记」展示**我自己的**划线/想法（需 Key）——两者是两回事。
> 本版为**待实测**首版，接口参数（`listType`）与 bookId 免权限获取方式是重点观察项。

## 一、入口与开关

- [ ] **1.1** 主菜单「设置」分组内出现「💭 评论」入口，位置在「📝 笔记」之后
- [ ] **1.2** 图标/命名与「💬 支持与反馈」不冲突（区分明显）
- [ ] **1.3** 首次打开阅读页时侧栏**默认显示**在右侧
- [ ] **1.4** 点主菜单「💭 评论」可**关闭**侧栏；再点可**重新打开**
- [ ] **1.5** 关闭后刷新页面/重开阅读页，侧栏仍保持关闭（开关已持久化）
- [ ] **1.6** 非阅读页（如主页/书架页）不出现侧栏

## 二、侧栏展示

- [ ] **2.1** 侧栏出现在阅读页**右侧**，带「💭 评论」标题、刷新 / 收起按钮
- [ ] **2.2** 副标题显示「《当前章节名》 · 共 N 条评论」
- [ ] **2.3** 每条评论卡片含：头像、昵称、时间（`YYYY-MM-DD HH:mm:ss`）、正文
- [ ] **2.4** 头像缺失时显示昵称首字圆形占位，不出现破图
- [ ] **2.5** 正文里的换行正常显示；不为空、不错位
- [ ] **2.6** 底部署名行固定显示「评论来自微信读书公开数据，仅在本机展示、不上传」

## 三、章节跟随（自动刷新）

- [ ] **3.1** 点击目录切到另一章，侧栏**自动刷新**为该章评论（副标题章节名同步变化）
- [ ] **3.2** 点「上一章 / 下一章」后，侧栏自动刷新
- [ ] **3.3** 连续快速切换章节，最终展示的与**最终所在章节**一致（无旧结果回填错乱）
- [ ] **3.4** 更换到另一本书，侧栏刷新为新书当前章节的评论

## 四、引用原文展开 / 收起

- [ ] **4.1** 带引用的评论，引用块默认**单行截断**
- [ ] **4.2** 点击引用块 → 展开完整原文；再点 → 收起
- [ ] **4.3** 引用原文里的特殊字符（`<` `>` `&` 等）按**纯文本**显示，不被当成 HTML 执行（防 XSS）

## 五、空态 / 加载 / 错误

- [ ] **5.1** 刚进入/刷新时先显示「正在读取评论…」
- [ ] **5.2** 当前章节无评论时显示「本章还没有评论」
- [ ] **5.3** 接口失败时显示**中文**原因 + 「重试」按钮；点重试可重新拉取
- [ ] **5.4** 未识别到当前章节时提示「请打开『目录』后再点刷新」，不崩溃
- [ ] **5.5** 任何异常都不阻断正文阅读、不弹 alert

## 六、折叠与主题

- [ ] **6.1** 点「收起」→ 侧栏收为右侧竖直小标签「💭 评论」
- [ ] **6.2** 点该小标签 → 侧栏重新展开
- [ ] **6.3** 浅色主题下侧栏为浅色；切到官方深色主题后侧栏为深色（前景/背景对比正常）
- [ ] **6.4** 侧栏为右侧浮层，**不改变正文宽度**；与「屏占比调节」互不冲突
- [ ] **6.5** 翻页模式与滚动模式下侧栏均正常显示、可交互

## 七、红线核对（隐私 / 权限）

- [ ] **7.1** `manifest.json` 的 `permissions` 仍只有 `storage`（**未新增** `webRequest` 等权限）
- [ ] **7.2** 评论数据**不写入** `chrome.storage`（仅内存展示，刷新即失效）
- [ ] **7.3** 现有功能（阅读统计 / 笔记 / 阅读洞察 / 屏占比 / 找书 / 备份 / 帮助）行为不变
- [ ] **7.4** `main` 菜单其余入口点击均正常，无「尚未实现」误报日志

## 八、接口标定（待实测，重点观察）

- [ ] **8.1** 控制台可见 `[reviews]` 日志：bookId 命中来源（网络记录 / 内联脚本 / book/info 反查 / 网址兜底）
- [ ] **8.2** 评论内容与条数**与微信读书移动端「想法」一致**（若不一致，记录实际 `listType` / 接口回包键名）
- [ ] **8.3** 若展示为「本章还没有评论」但移动端明明有评论 → 记录 `[reviews] 评论拉取完成` 日志的 `raw` / `keys` / `url`，回填标定
- [ ] **8.4** 若报「未识别到书籍 ID」→ 记录 `[reviews] 未能取到数字 bookId`，回填标定
