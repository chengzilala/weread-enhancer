「阅读人格」是「🪞 阅读洞察」里的首屏：它不看问卷，而是从**你真正读过的书、划过的线、写下的想法**里，把你这个人推出来。结果是一个 **4 位字母代码 + 一个主称号**（16 型「读书人」之一），全部在你本机计算。

> [!note] 先说明它是什么
> 这是一份**基于阅读行为数据的趣味性参考画像**，参考了 MBTI 的四维结构，但**不是心理测评，也不构成专业性格鉴定**；对外不使用 MBTI® 商标。

## 一、怎么生成

1. 在「🔑 API Key」里配好 `wrk-` Key（见 [[API Key 使用说明]]）
2. 打开「🪞 阅读洞察」→ 报告首屏「🧬 我的阅读人格」
3. 点「📊 启用分析」——这时才读取你**笔记最多几本书（最多 5 本）的划线 / 想法**，在本机判定，生成人格卡与词语分析
4. 想要更自然的文案，再点「🤖 生成 AI 解读」（可选，会把原文样本发送给 DeepSeek）

不点按钮就不联网、不消耗请求；数据不够时先告诉你还差多少（累计 **≥10 小时** 且笔记 **≥20 条** 才会生成）。

## 二、结果里有什么

- **人格卡**：4 位代码 + 主称号 + 三个特质绰号 + 一句定调；
- **四维进度条**：每一维给左右两极与百分比（如「深潜 78% ↔ 22% 广撒」）；
- **证据区**：数据证据（累计时长 / 划线数 / 想法数 / 书架本数）＋ 2~3 条真实原文引用（带书名与年份）；
- **词语分析**：高频词 TOP10、情绪比例、你的口头禅、主题词；
- **手机版分享图**：竖版图片，可一键「📋 复制图片」或「⬇️ 下载图片」。
