快捷键：几个键管住全部

插件快捷键

按键作用
空格开始 / 暂停自动阅读（按设定节奏自动往下翻页）
D勿扰模式开关（隐藏悬浮图标，专注阅读）
F全屏模式开关（保留屏占比与勿扰状态）
?打开 / 关闭帮助面板

微信读书原生（插件不拦截）

按键作用
← / →上一页 / 下一页
Esc退出全屏（屏占比自动恢复）

输入法状态也能用

? 已按物理键识别，中文输入法组词状态下也能打开面板。

[!tip] 这些情况下不触发 光标在输入框 / 文本框内时不触发；Ctrl / Alt / Cmd 组合键也不触发（避免和浏览器自带快捷键打架）。
