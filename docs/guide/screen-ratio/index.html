屏占比调节：让正文更宽

微信读书网页版默认会把正文限制在中间一条，两侧留白很多。屏占比就是用来把这条「正文区」拉宽的。

怎么调

  1. 移到右下角悬浮球 → 打开菜单 → 「阅读设置」
  2. 拖动屏占比滑块（50%–100%），正文宽度即时变化
  3. 也可以用快捷按钮一步到位：100 / 90 / 80 / 70

设置在浏览器本地保存，刷新后自动恢复。

屏占比调高之后会顺带发生什么

正文变宽之后，微信读书原本的顶部工具栏和右侧按钮可能会被挤出视线之外。插件在这种情况下会改成浮动显示：

  • 鼠标移到屏幕顶部边缘 → 顶部工具栏淡入
  • 鼠标移到屏幕右侧边缘 → 右侧功能按钮淡入
  • 鼠标移开 → 自动淡出，不挡正文

所以你可以放心把屏占比拉到 100%，翻页和切章节的按钮还在。

如果你习惯用鼠标靠边操作

浮动工具栏是靠「鼠标贴边」呼出的，把鼠标甩到顶边／右边即可；不需要点击。
