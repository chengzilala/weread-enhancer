分享图与隐私

算出人格卡后，插件能把它一键做成一张竖版手机图，随手发到手机微信 / 朋友圈 / 群聊。这一页讲清图里有什么、怎么用、隐私边界在哪。

一、分享图里有什么

自上而下固定四块：

  1. 人格卡主体：人格代码（大字）+ 主称号 + 三个特质绰号 + 一句定调 + 四维进度条；
  2. 词语分析亮点：高频词 TOP3 + 「你的口头禅」（带书名）；
  3. 数据证据：累计时长（小时）/ 划线数 / 想法数 / 书架本数；
  4. 品牌署名：微信悦读 · wereadapp-32km31c.maozi.io + 一句「基于我的微信读书数据生成」。

图片规格

逻辑宽 1080px、按 2× 超采样导出（实际像素宽 2160px），手机上清晰、朋友圈缩略图也可辨；固定浅色底 + 品牌色（不跟随插件主题，避免深色底在缩略图里看不清）；用系统字体、不含随机，同一份数据永远生成同一张图。

二、怎么用

  • 📋 复制图片：把 PNG 写进系统剪贴板，随后到手机微信里粘贴即可发送；
  • ⬇️ 下载图片：保存为 阅读人格-{代码}.png（如 阅读人格-DFLP.png）；
  • 若某环境「图片写剪贴板」不可用，会自动降级为下载 PNG——不擅自新增浏览器权限。
  • 不做「直接唤起微信 / 发朋友圈」：浏览器与扩展没有这个能力，需求只承诺「生成 + 复制 + 下载」，其余由你手动完成。

数据不足时不生成分享图，与人格卡一致走「还差一点数据」的引导态，缺哪几维就说明缺哪几维。

三、隐私边界

  • 分享图不含任何账号标识 / 隐私字段：没有昵称、没有头像、没有 uid；
  • 图里只有聚合数据，以及你主动选择展示的原文引用（如划线与想法）；
  • 生成全程在本机完成、不外发；V1 的分享图不含二维码，只以文字域名做品牌归属。
