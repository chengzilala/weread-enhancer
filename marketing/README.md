## 约定

- 新增文案：**按渠道建文件**（如 `小红书文案.md`、`公众号推文.md`），在本表补一行。
- **口径红线**：只讲已实现功能、不夸大；快捷键仅 `空格 / D / F / ?`（不写 `T`）；语音一律「朗读 / 听」；小程序「悦读且住」未发布前不写进文案。
- 图 + 文配套：图片见 `screenshots/素材清单.md`，文案见本目录，两边互相登记。
