这里汇总微信悦读的**全部界面图**，按**功能模块**分组。所有图片都是插件的**真实界面**，不是效果图。**点击任意图片可看大图**（按 `Esc` 或点空白处关闭）。

> [!note] 关于分类
> 同一功能在 GitHub、商店、360 有不同尺寸的成品。前六组按「能干什么」分组，展示每个功能的展示卡片；最后一组放各渠道的上架尺寸件（磁贴 / 截图 / 效果图）。

## 阅读统计与导出

统计前台阅读时长（今日 / 本周 / 本月 / 本书），一键导出 HTML 报表 / PDF / Markdown / CSV / JSON。

![阅读统计与数据导出](/assets/img/gallery/feature-06-stats.png)

## 笔记增强

把本书全部划线与想法按章节聚合，搜索定位、一键复制、多格式导出。

![笔记增强](/assets/img/gallery/feature-07-notes.png)

## 阅读洞察
