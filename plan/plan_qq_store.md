## 二、已核实的事实（安装侧，2026-10-04）

- QQ 浏览器基于 **Chromium** 内核，**支持 MV3 扩展**（本地可加载 `.crx` / 解压目录）。
- 用户安装入口（官方帮助）：
  - 菜单 → **扩展程序** → 扩展中心（在线安装）
  - `qqbrowser://extensions` → 开**开发者模式** → 拖 `.crx` / **加载已解压的扩展程序**
- ⚠️ QQ 浏览器**不能**从 Chrome 商店「一键在线安装」：国内版移除了该通道，且 `chrome.google.com` 国内访问受限。
  → 用户想在 QQ 浏览器里**搜到并一键装**，**必须走 QQ 自己的商店**；否则只能手动离线加载（对普通用户门槛高）。

## 三、第一步（关键）：确认提交渠道

按顺序尝试，任一拿到明确答复即可：

1. **QQ 浏览器官方反馈入口**：https://feedback.browser.qq.com
   说明：想上架扩展「微信悦读」，留 QQ 号等联系方式，请官方评估接入（该入口官方文案称「个人开发者/产品负责人都欢迎接入」，**先问清是否含浏览器扩展**）。
2. **QQ 浏览器官网 / 客服**：https://browser.qq.com 找「反馈 / 联系」。
3. **腾讯开放平台官方邮箱（用于问路）**：`qq_open@tencent.com`，说明需求并请其转交 QQ 浏览器团队。
4. 找**已上架 QQ 商店的扩展开发者**，问其实际提交入口。

> 口径：**渠道确认前，本商店保持「待核实」**，不制作专用素材、不提审。
