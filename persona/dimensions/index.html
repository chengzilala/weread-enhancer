四维详解

阅读人格的四位代码，就是下面四维各出一位字母。每一维都输出「字母 + 判定值（0~100）+ 一句依据」，判定值画成进度条，依据写进结果页的「证据区」。

两件先说清楚

  • 本机算、可复算：四维判定是纯算术，不含随机、不依赖 AI，同一份数据永远得出同一结果。
  • 居中与缺失是正常的：某一维读数落在中间带会被标「居中」；数据不足时该位显示 –，其余照常。

D1 阅读能量：深潜 D ↔ 广撒 B

  • 在问什么：你是把一本书读穿，还是同时开着很多本？
  • 看哪些数据：单本均摊时长、书架前 3 类集中度、电子书完读率、有笔记的书数（并行度）。
  • 怎么判：几项指标加权后，单本投入越多、口味越集中 → 偏 D；翻得广、口味分散 → 偏 B。
  • 居中带：45%~55%。
  • 绰号参考：深潜者 / 杂食派。

D2 内容取向：求实 F ↔ 求意 M

  • 在问什么：你更想要「能用上的」，还是「想明白些的」？
  • 看哪些数据：优先用官方偏好分类（按阅读时长）；拿不到时用书架分类（按本数）。
  • 两组怎么分：
    • 求实组：职场 / 经济·理财 / 科技·互联网 / 自我提升 / 健康 / 教育 / 工具等
    • 求意组：文学 / 历史 / 哲学 / 心理 / 社科 / 艺术 / 传记等
  • 怎么判：某组占比 ≥60% → 判该极；落在 40%~60% 之间 → 取占比高者但标「居中」。
  • 居中带：40%~60%（比其余三维更宽，因为分类本身就有模糊地带）。
  • 绰号参考：解决问题的人 / 意义收集者。

D3 表达方式：理性 L ↔ 感性 E

  • 在问什么：你的划线和想法，是在「分析」还是在「共情」？
  • 看哪些数据：对你笔记语料（划线 + 想法正文）做本地词表计数——逻辑词（因为 / 本质 / 结构 / 系统…）与情感词（喜欢 / 感动 / 温暖…）各占多少；再辅以问号、感叹号占比。
  • 怎么判：情感词占比高于逻辑词 → 偏 E；反之偏 L。语料太少时这一维可能显示 –。
  • 居中带：45%~55%。
  • 绰号参考：拆解者 / 共情者。

D4 阅读节奏：计划 P ↔ 随兴 R

  • 在问什么：你是「按计划读」，还是「随缘漂」？
  • 看哪些数据：有阅读的统计单元占比、时间分布的波动系数、偏好分类在不同时段是否稳定。
  • 怎么判：越规律、波动越小 → 偏 P；跳跃、漂移大 → 偏 R。
  • 居中带：45%~55%。
  • 绰号参考：清单执行者 / 缘读者。

四个字母 → 一个称号

四维全算出来后，四位字母拼成一个代码，对应 16 型图鉴 里的一个主称号。除主称号外，结果页还会给你三个特质绰号（来自你的四维极点、客观画像标签与阅读时段，例如「深潜者 · 拆解者 · 夜读者」）。
