# 360 浏览器扩展 上架 / 归档文档（macOS / Apple Silicon 版）

> **文档类型**：商店上架方案 + 归档记录（360 浏览器）
> **创建日期**：2026-07-07 ｜ **重写为 Mac 版**：2026-09-27
> **适用设备**：**macOS + Apple Silicon（M 系列芯片）**，360 安全浏览器 macOS 版
> **对应版本**：v0.8.2（Manifest V3）
> **关联文档**：`plan/plan_edge_store.md`、`plan/plan_chrome_store.md`、`plan/session_handoff_商店上架.md`
> **说明**：本版面向「**Mac 用户、从未用过 360 开放平台**」，从装浏览器讲起。360 开放平台较老、Mac 版 UI 与 Windows 有差异，**一切以你屏幕上实际页面为准**。
> ⚠️ 若你的 360 Mac 版**没有**「开发者模式 / 加载已解压的扩展程序」，说明该版本不支持本地扩展调试，需改到 Windows 环境做（见第五节「不支持时的备选」）。

---

## 〇、总览：你要做的 7 件事

1. 注册并登录 **360 账号**（通行证）
2. 安装 **360 安全浏览器 macOS 版**（Apple Silicon 原生）
3. 打开**扩展管理页**、开启**开发者模式**（Mac 上入口隐蔽，见第四节）
4. **实测 MV3 兼容性**（插件能否在 360 正常跑）—— 能否上架的前提
5. 把插件**打包成 `.crx`**（并保存 `.pem` 私钥）
6. 准备上传素材（功能说明 txt + 指定尺寸图片），连同 `.crx` **一起压成 ZIP**
7. 在 360 开放平台**上传 ZIP、提交审核**

> 其中第 4、5、7 步必须在你自己的 Mac 上手动操作；第 6 步的素材我已备好（`release/360-素材/`）。

## 二、第 1 步：注册并登录 360 账号

360 开放平台用 **360 账号（360 通行证）** 登录，**免费**。

1. 打开 https://open.chrome.360.cn ，右上角「**登录 / 注册**」。
2. 没有账号就先注册通行证（任选其一）：
   - **手机号注册（最简单）**：手机号 → 短信验证码 → 设密码。
   - **邮箱注册**：邮箱 + 密码 → 到邮箱点激活链接。
   - 也可直接访问通行证：`https://i.360.cn`。
3. **实名认证 / 开发者信息**：首次发布前平台可能要求补实名，**以登录后页面提示为准**。

---

## 三、第 2 步：安装 360 安全浏览器（macOS 版）

- 官网：`https://360browser.cn`（另有 `https://browser.360.cn`）→ 选「**macOS**」下载。
- macOS 版基于 **Chromium 108** 内核，**原生支持 Apple Silicon（M 系列）**，无需 Rosetta。
- 安装：下载 `.dmg` → 双击 → 把 360 安全浏览器图标拖进「应用程序」文件夹。
- 首次打开若被 macOS 拦截（"无法验证开发者"）：**系统设置 → 隐私与安全性** → 点「仍要打开」。

> 关于内核：Chromium 108 支持 Manifest V3，本插件**理论上能跑**；但 360 Mac 版的扩展能力可能被裁剪，**必须实测**（第五节）。

---

## 四、第 3 步：打开扩展管理页 + 开启开发者模式 ★（你卡住的地方）

360 安全浏览器 Mac 版的「开发者模式」**入口很隐蔽**，不在常规设置里。按下面顺序逐个试（任意一个能打开管理页即可）：

**地址栏逐个输入并回车：**
1. `se://extensions/`  ← 360 安全浏览器最常见入口
2. `chrome://extensions`
3. `chrome://myextensions/extensions`
4. `chrome://plugin-manager`

**或从界面进入：**
5. 右上角「**拼图 / 扩展**」图标 → 下拉里选「**管理扩展**」
6. 右上角「**☰ 菜单**」→ 找「**扩展程序**」/「**扩展中心**」/「**插件管理**」

进入后：
- 找到 **「开发者模式」**（有的版本叫「**开发人员模式**」）开关 → **打开**。
- 打开后页面顶部/底部会出现两个按钮：**「加载已解压的扩展程序」** 与 **「打包扩展程序」**。
- 若开关旁边有 `+` 号，点 `+` 展开。

> **判定**：只要能看到「**加载已解压的扩展程序**」按钮 = 该 Mac 版**支持**本地扩展 → 继续第五节。
> 若以上 6 个入口都打不开、或开了开发者模式也**没有**这两个按钮 = 该 Mac 版**不支持**本地扩展调试 → 见第五节「不支持时的备选」。

---

## 五、第 4 步：实测 MV3 兼容性（关键，先做）

1. 先解压上架包得到干净目录：
   解压 `release/weread-enhancer-v0.8.2.zip` → 得到含 `manifest.json`、`content.js`、`content.css`、`README.md`、`icons/` 的文件夹。
2. 在第四节的扩展管理页 → 点「**加载已解压的扩展程序**」→ 选**那个文件夹**（含 `manifest.json` 的目录）。
3. 打开 `https://weread.qq.com` 任一书籍页，**逐项验证**：
   - 右上角控制面板出现
   - 屏占比调节（滑块 + 快捷比例按钮）
   - 自动阅读（**空格**）
   - 勿扰（**D**）、全屏（**F**）、帮助面板（**?**）
   - 设置能保存（刷新页面后仍生效 = `chrome.storage` 正常）
4. 结果：
   - ✅ **正常** → 继续第六节打包上架。
   - ❌ **异常**（面板不出 / 报错 / 存储失效）→ 先把现象记到第十节归档表，再决定是否维护 MV2 版（属代码改动，**需先确认**）。

### 不支持时的备选（Mac 版无「加载已解压」按钮）
- **借一台 Windows**：在 Windows 版 360 浏览器里做第 4~6 步（打包 crx），再回到 Mac 上传。
- **用 Chrome/Edge 先验证逻辑**：你的插件在 Chrome/Edge（同为 Chromium、MV3）已实测通过，可先确认代码本身没问题；但 360 仍建议真机过一遍。

---

## 六、第 5 步：在 Mac 上打包成 `.crx`

> 前提：第四节能看到「**打包扩展程序**」按钮。

1. 扩展管理页 → 点「**打包扩展程序**」。
2. **扩展程序根目录**：填刚解压的干净目录，例如
   `/Users/Admin/Knowledge/Coding/微信读书插件/release/weread-enhancer-v0.8.2`
   （**首次打包，「私有密钥文件」一栏留空**）
3. 点「确定」→ 在**上一级目录**生成两个文件：
   - `weread-enhancer-v0.8.2.crx`（扩展包）
   - `weread-enhancer-v0.8.2.pem`（**私钥**）

> ⚠️⚠️ **`.pem` 是更新版本的命根子**：丢了以后就只能当全新应用重新上架。请把它移到安全位置（如 iCloud 钥匙串 / 加密盘），**绝不提交到 git**、不要发到聊天里。

**若 Mac 版没有「打包扩展程序」按钮**：改用 Windows 版 360 浏览器打包，或尝试上传 ZIP 后由平台自动生成 crx（360 文档提到开放平台上传可自动生成 `.crx`，以实际上传页提示为准）。

## 七、第 6 步：准备上传素材（在 Mac 上打成一个 ZIP）

> 360 上传的是**一个 ZIP**，里面包含 **`.crx` + 说明文档 + 图片**，不是直接传 crx。

素材清单（依 360 上传须知）：

| 素材 | 格式 / 尺寸 | 必需? | 本项目现状 |
|---|---|---|---|
| 应用文件 | `.crx` | ✅ 必需 | 第六节生成（**尚未生成**） |
| 功能说明文档 | `.txt` | ✅ 必需 | ✅ `release/360-素材/功能说明.txt` |
| 详情页展示图标 | PNG **48×48** | ✅ 必需 | ✅ `release/360-素材/图标-48x48.png` |
| 效果图（截图） | PNG **560×350**，1–5 张 | ✅ 必需 | ✅ `release/360-素材/效果图-01~05-560x350.png`（带品牌蓝标题栏，由 `promo.py` 生成） |
| 新标签推荐图标 | PNG **96×96** | 可选 | 无（如需再做） |
| 扩展中心轮播图 | PNG **583×204** | 可选 | 无（如需再做） |
| 新标签页推荐图 | PNG **278×162** | 可选 | 无（如需再做） |

> ⚠️ 360 图片尺寸（48×48 / 560×350 / …）与 Chrome/Edge（1280×800 / 440×280）**完全不同**，Edge 截图**不能直接复用**；本项目已按 560×350 单独生成（`release/360-素材/`，跑 `python3 promo.py` 可重新生成）。
> ℹ️ Edge/Chrome 用 `screenshots/store/`，GitHub README 用 `screenshots/promo/`，三者互不混用。

**组装（Mac 上用访达）：**
1. 新建一个文件夹（如 `360上传包`）。
2. 把第六节生成的 `.crx` 放进该文件夹。
3. 把 `release/360-素材/` 里**全部文件**（功能说明.txt、图标-48x48.png、效果图 01~05）也放进去。
4. 右键该文件夹 → **「压缩…」** → 得到 `360上传包.zip`，即上传包。

---

## 八、第 7 步：上传并提交审核

1. 登录 https://open.chrome.360.cn → 进入开发者 / 上传应用入口。
2. 阅读并接受《开发人员协议》。
3. 上传第七节的 **ZIP 包**。
4. 按页面填写：名称、分类、描述（用第九节文案）、隐私政策 URL 等。
5. 提交后由 360 做**人工 + 多引擎检测**审核。
6. 通过后上架到 **360 浏览器应用中心**。
7. 把提交日期、审核结果、链接记到第十节。

> - 首次安装/更新弹出新手引导
> - 零依赖、不收集任何用户数据，仅在 weread.qq.com 下运行

## 十一、注意事项

- **先测后用**：第四节先确认 Mac 版能加载扩展，再往下做；不能加载就别急着做素材。
- **保存 `.pem`**：更新版本的命根子，勿丢、勿提交 git。
- **上传是 ZIP（内含 crx + 素材）**，不是单个 crx。
- **360 图片尺寸独立**（48×48 / 560×350…），效果图已按 560×350 另裁。
- 权限最小（仅 `storage`）、无远程代码/分析/广告，利于过审。
- 隐私政策 URL、支持邮箱、名称与 Edge/Chrome 保持一致，便于统一维护。
- **注册账户、点「提交审核」由你手动完成**；未经你明确要求，我不注册账户、不代替提交。
