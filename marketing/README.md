## 约定

- **通用要求以 [发帖规范.md](./发帖规范.md) 为准**：口径红线、入口四件套、配图 / 文案要求、发布前校验清单，各渠道一致；渠道只在各自 `运营计划.md` 里写「差异」。
- 新增文案：**按渠道建文件**（如 `公众号推文.md`），在本表补一行。
- **口径红线**：只讲已实现功能、不夸大；快捷键仅 `空格 / D / F / ?`（不写 `T`）；语音一律「朗读 / 听」；小程序「悦读且住」**每帖底部固定带一行** `🔍 微信小程序：微信搜「悦读且住」`（**未上线也写**）。
- 图 + 文配套：图片见 `screenshots/素材清单.md`，文案见本目录，两边互相登记。
