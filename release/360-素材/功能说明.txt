微信悦读（v0.15.1）

一款专为微信读书网页版（weread.qq.com）打造的阅读增强扩展。

核心功能：
- 自定义屏占比：50%-100% 自由调节阅读区域宽度，滑块 + 快捷比例按钮，设置自动保存
- 工具栏浮动悬停：屏占比 ≥90% 时自动隐藏原生工具栏，鼠标移到顶部/右侧感应区淡入显示
- 滚动模式增强：正文屏占比自适应居中不溢出，配自绘悬浮滚动条（鼠标靠右淡入、可拖动跳转），刷新后记忆
- 自动阅读：速度滑块 + 方向切换 + 开始/暂停，空格键快捷控制
- 快捷键：空格（自动阅读）、D（勿扰）、F（全屏）、?（帮助/调试面板）
- 勿扰模式：隐藏干扰元素，专注沉浸阅读
- 全屏模式：F 键切换，保留屏占比/勿扰状态，退出自动恢复
- 新手引导 / 刷新记忆：首次安装或版本更新弹出欢迎面板；刷新页面后自动恢复上次的全部设置
- 阅读统计与数据导出：统计前台阅读时长（今日/本周/本月/本书），显示当前书籍进度与最近 10 本书（可点击跳转），一键导出 HTML / PDF / Markdown / CSV / JSON
- 笔记增强：菜单「笔记」一键聚合本书全部划线与想法/批注（按章节分组，内置搜索框实时定位），支持一键复制（富文本 + 干净纯文本）与 Markdown / 纯文本 / HTML / PDF 导出；选中正文文字即弹出「复制」浮标，自动清洗官方水印后再复制。读取笔记需先配置官方 API Key
- 官方数据（阅读行为报告）：在菜单「API Key」粘贴自己的微信读书 wrk- API Key 后，拉取官方口径阅读数据，在本机生成「阅读行为报告」（核心指标 / 阅读轨迹与时间线 / 偏好画像 / 成就勋章 / 完读率 / 已读完书目 / 阅读人格画像等），支持本周/本月/本年/累计四种周期切换，一键导出 Markdown / HTML / PDF。可选接入自己的 DeepSeek Key，把「执行摘要」升级为 AI 人格化解读（数字仍在本机计算）
- 诊断日志：内置调试日志系统，可导出为 JSON 文件辅助排查问题
- 帮助中心：主菜单一键跳转配套网站；有新版本时在入口旁显示红点提示

隐私说明：
- 仅使用 storage 权限保存用户设置到浏览器本地；不包含任何统计、追踪或广告代码；仅在 weread.qq.com 下运行。
- 除以下场景外不向任何服务器发送数据：①「笔记增强」只访问微信读书官方同源接口 weread.qq.com，读到的笔记仅存内存、不落盘、不上传；②「官方数据」为可选功能，仅在你自行配置 API Key 后，才会把该 Key 与请求发送到微信读书官方网关 i.weread.qq.com，报告在你的浏览器本机生成；③「AI 解读」为可选功能，仅在你自行配置 DeepSeek Key 后，才会把已在本机算好的报告摘要与少量笔记样本发送到 api.deepseek.com（微信读书 Key 绝不发送给 DeepSeek）；④ 启动时向配套网站发起一次不含任何用户标识的匿名 GET 请求，用于检查是否有新版本，结果本地缓存 24 小时，失败即静默忽略。
- 你的 API Key 只保存在本机 chrome.storage.local，绝不会发送给插件作者或任何第三方。
