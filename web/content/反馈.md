## 提问题 / 报 Bug

到 GitHub 开一个 issue（需要 GitHub 账号）：

[chengzilala/weread-enhancer/issues](https://github.com/chengzilala/weread-enhancer/issues)

写的时候带上这几样，能省一轮来回：

- 你用的浏览器与版本（例如 Edge 130）
- 插件版本（页脚或 `edge://extensions/` 里能看到）
- 你做了什么、期望怎样、实际怎样
- 涉及页面显示问题时，附一张截图

## 想要新功能

同样开 issue，标题写清「希望支持：xxx」，简单说一下你在什么场景下需要它。不保证都做，但都会看。

## 其他

- 安全问题或隐私相关：请走 issue，并在标题标注「隐私」
- 反馈里请不要贴 API Key 或任何个人信息
