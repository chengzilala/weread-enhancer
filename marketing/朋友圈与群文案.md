**四端入口（备查，文案里按需取用）**

| 电脑插件 | Edge 商店搜「微信悦读」；链接 https://microsoftedge.microsoft.com/addons/detail/微信悦读/nkcckbonpafeclefhlhbencibkaabmgb |

**发布要点**
1. **朋友圈**：外链默认不可点 → 正文写「评论区自取」，链接放**第一条评论**。
2. **朋友群**：链接可直接点，大群建议先发短版、再补长版。
3. **配图**：首图优先用「阅读人格」竖版分享图（最易引发互动），次图放官网首页或插件界面截图。
4. **分流**：电脑插件仅 Edge / Chrome **桌面**浏览器可装；纯手机用户直接引导到 H5。
5. **不夸大**：不写「永久免费 / 绝对无广告」等承诺；只如实说「只在微信读书运行、数据存本地、不上传你的阅读数据」。

## 6. 事实口径（以代码 / 文档为准，勿凭印象改）

- **快捷键**：仅 `空格 / D / F / ?`（依据 `content.js`）；**任何文案都不要写 `T`（主题已取消）**。
- **权限**：仅 `storage` + 3 条主机权限（`i.weread.qq.com` / `api.deepseek.com` / 官网）；**仅 `weread.qq.com` 生效**；无远程代码。
- **语音复习**：一律用「朗读 / 听」，**不写"音频分享 / 导出"**（划线属书中原文，不提供音频导出）。
- **隐私**：插件有 1 条「匿名活跃统计」（不含阅读数据 / Key / 书目 / IP，默认开启、可在设置里关）；推广文案不展开，只说「不上传你的阅读数据」。
- **小程序**：未正式发布前不写进文案。
