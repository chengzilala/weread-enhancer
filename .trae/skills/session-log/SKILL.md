# 会话记录（6 段摘要落盘）

## 使用场景
每次会话开始起一条条目；每完成一个重要阶段，追加一段摘要到 `dev/session_log.md`。

## 指令
1. 会话开始：在 `session_log.md` 新增条目标题 `## {{日期}} 会话条目：{{标题}}（进行中）`。
2. 每完成一个阶段，按**固定 6 段**追加（逐条填，不留空）：
   ```
   - 目标：
   - 已做：
   - 关键结论/决定：
   - 产出物（文件/链接）：
   - 待办：
   - 风险/注意事项：
   ```
3. 只留要点：不粘长段原对话，不重复贴大段代码（代码只写文件路径）。

## 红线
- 严禁把密钥 / token / 隐私写进 `session_log.md`。
- 用户说"本次不写 session_log"时，只在对话里给摘要。
