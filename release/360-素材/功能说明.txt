微信悦读（v0.24.0）

一款专为微信读书网页版（weread.qq.com）打造的阅读增强扩展。

核心功能：
- 自定义屏占比：50%-100% 自由调节阅读区域宽度，滑块 + 快捷比例按钮，设置自动保存
- 工具栏浮动：屏占比 ≥90% 时自动隐藏原生工具栏，鼠标移到顶部/右侧边缘淡入显示，点击正常
- 滚动模式增强：正文屏占比自适应居中不溢出、工具栏浮动、自绘悬浮滚动条（靠右淡入、可拖动跳转），刷新后记忆
- 自动阅读：速度与方向可调，空格键一键开始/暂停
- 快捷键：空格（自动阅读）、D（勿扰）、F（全屏）、?（帮助/调试面板）
- 勿扰模式：隐藏干扰元素，专注沉浸阅读
- 全屏模式：一键进入沉浸全屏，退出自动恢复
- 新手引导：首次安装或版本更新时弹出欢迎面板
- 阅读统计与导出：统计阅读时长（今日/本周/本月/本书）、当前书籍进度与最近阅读，一键导出 HTML / PDF / Markdown / CSV / JSON
- 笔记增强：聚合本书划线与想法/批注（按章节分组 + 关键词搜索），支持一键复制与 Markdown / 纯文本 / HTML / PDF 导出；选中正文即弹出「复制」浮标并自动清洗官方水印；支持「▶ 听」用浏览器内置语音朗读（本机合成、不上传、零权限）
- 阅读洞察（阅读行为报告）：粘贴自己的微信读书 API Key 后，本机生成含图表可视化（时长趋势 / 偏好分类 / 阅读时段 / 完读率）的阅读行为分析报告，并附「阅读人格」（读书人版，16 型人物线描插画，可选 AI 润色）；面板内含「书架」「发现」页签，可看书架汇总、搜书、推荐、公开书评与相似书；可选接入 DeepSeek 生成 AI 人格化解读
- 本地找书：在插件内自建本地标签层（只存本机、不写回微信读书），给书架书目打标签，并按书名 / 作者 / 标签 / 拼音首字母 / 笔记数量区间 / 阅读状态 / 最近阅读多维度搜书；可检索自己的划线·想法正文；支持标签管理与导出/导入 JSON
- 支持与反馈：打赏 / 反馈 / 公众号入口；帮助中心一键跳转配套网站
- 匿名使用统计（默认开启、可一键关闭）：每天至多上报一次「活跃」，内容仅随机匿名标识 + 版本号 + 事件名，绝不包含阅读数据 / Key / 书目 / 笔记
- 中英双语：非中文浏览器下显示英文名称与简介

说明：笔记增强与阅读洞察需先在「🔑 API Key」入口配置你自己的微信读书 API Key；DeepSeek 为可选增强，不配置也能正常使用。

隐私说明：仅使用 storage 权限把设置保存在浏览器本地；仅在 weread.qq.com 下运行。笔记增强 / 阅读洞察会访问微信读书官方接口（i.weread.qq.com），可选 AI 增强会访问 api.deepseek.com，匿名使用统计会上报至自建统计接口（*.tcloudbase.com）；访问外部接口均只处理与该功能直接相关的数据，除「随机匿名标识 + 版本号 + 事件名」的匿名使用统计外，不收集、不上传任何其他数据（统计可在设置内一键关闭）。
