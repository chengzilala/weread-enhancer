# 内容结构说明

网站的全部文字内容都写在 **`web/content/`**（一个独立的 Obsidian vault）。
写完在终端跑一条命令即可发布：

```
python3 web/build.py
```

- 产物在 `web/dist/`，**不要手改**（每次构建都会清空重建）。
- 本 vault 只放「会被发布的内容」；草稿用 front-matter 的 `draft: true` 挡住。

---

## 一、网站布局 ↔ 文件对照（唯一权威）

> 参考 flomo：官网（`/`）只讲「是什么」；**用法教程独立成一个文档站，挂在 `/docs/` 下**，
> 顶栏只留少量入口，其余都收进 `/docs/` 的左侧目录树。

**顶栏（由 `site.config.json` 的 `nav` 决定）：**

| 顶栏导航 | 源文件 / 文件夹 | 网址 | 说明 |
|---|---|---|---|
| 首页 | `content/首页.md` | `/` | 落地页，`slug` 留空 |
| 帮助文档 | 见下方「帮助文档站目录」 | `/docs/` | 顶栏入口，指向文档站首页 |
| 图库 | `content/界面图库.md` + `web/assets/img/gallery/` | `/gallery/` | 单篇页；图片单独放 |
| 关于 | `content/关于.md` | `/about/` | 单篇 |
| 打赏 | 无 md，由 `build.py` 生成（数据 `web/donate.json`） | `/donate/` | — |
| 登录 | 无 md，由 `build.py` 生成 | `/account/` | 顶栏右下角按钮与本站 `/account/` 均走统一账户中心（`wxread`）；账户码 + Key 托管在网页版 `/app/` 的「我的」里 |
| 装到 Edge | `site.config.json` 的 `storeUrls.edge` | 外部商店链接 | 顶栏主行动按钮 |

**帮助文档站（`/docs/` 下，分组与顺序由 `site.config.json` 的 `docs.tree` 决定）：**

| 目录树分组 | 源文件 / 文件夹 | 网址 |
|---|---|---|
| 🚀 开始 | `content/快速上手.md` | `/docs/start/` |
| 📖 功能教程 | `content/功能教程/` | `/docs/guide/` + `/docs/guide/*` |
| 🧠 进阶技巧 | `content/进阶技巧/` | `/docs/tips/` + `/docs/tips/*` |
| 📱 H5 移动端 | `content/H5 移动端/` | `/docs/h5/` + `/docs/h5/*` |
| 💬 微信小程序 | `content/微信小程序/` | `/docs/miniapp/` + `/docs/miniapp/*` |
| ✨ 阅读人格 | `content/阅读人格/` | `/docs/persona/` + `/docs/persona/*` |
| 📚 知识资产 | `content/知识资产/` | `/docs/thinking/` + `/docs/thinking/*` |
| ❓ 常见问题 | `content/常见问题.md` | `/docs/faq/` |
| 🧾 更新日志 | `content/更新日志.md` | `/docs/changelog/` |

> 搬迁约定：内容页一律挂在 `/docs/` 下；只有「首页 / 关于 / 图库 / 隐私政策 / 反馈」这 5 个官网页面留在根目录。
> 旧地址（如 `/guide/`、`/start/`、`/guide/stats/`）由构建自动生成「跳转页」，永久指向新的 `/docs/…`。

**页脚 / 其它入口（不在顶栏）：**

| 入口 | 源文件 | 网址 |
|---|---|---|
| 反馈 | `content/反馈.md` | `/feedback/` |
| 隐私政策 | `content/隐私政策.md` | `/privacy/` |
| H5 网页版 | `h5/` 源码，构建时拷入 | `/app/` |

新建文章复制 `content/_模板.md`（下划线开头，不参与构建）。

## 二、两条铁律

1. **文件夹名 = 栏目名**
   `content/` 下的一级文件夹名，必须与 [`web/site.config.json`](../site.config.json) 里 `sections[].dir` **逐字一致**：
   `功能教程`、`进阶技巧`、`H5 移动端`、`微信小程序`、`知识资产`、`阅读人格`。
   （改动栏目 = 同时改文件夹名和 site.config.json，两处必须一起改。）

2. **单篇页 = vault 根文件**
   首页、快速上手、图库、常见问题、更新日志、关于、反馈、隐私政策、创作手记是单篇，直接放在 `content/` 根目录，靠各自 front-matter 的 `slug` 决定网址。

---

## 三、新增 / 修改一篇文章

1. 复制 `_模板.md` 到目标位置（栏目文章放对应文件夹，单篇放根目录）。
2. 改 front-matter：`title` / `slug` / `description` / `updatedAt`，需要排序再写 `order`。
3. `draft` 改 `false` 才会被构建（草稿保持 `true`）。
4. **`slug` 写死一次就别再改**（它就是网址；改文件名不影响已发布的链接）。
5. 正文可用 Obsidian 语法：`[[双链]]`、`![[图片.png]]`、`> [!note] / [!tip] / [!warning]` 提示框。
6. 跑 `python3 web/build.py`，看输出「告警 0 条」即成功。

---

## 四、front-matter 字段

| 字段 | 作用 |
|---|---|
| `title` | 页面大标题 + 列表里显示的名字 |
| `slug` | 网址；内容页会自动挂到 `/docs/` 下（如 `guide/stats` → `/docs/guide/stats/`）；官网页面留原样、首页留空 |
| `order` | 栏目内的排序（越小越靠前） |
| `description` | 一句话摘要，用于列表与搜索引擎 |
| `updatedAt` | 更新日期 |
| `draft` | `true` 不发布 |
| `aliases` | 别名，供 `[[双链]]` 命中 |
| `tags` | 标签（预留） |

---

## 五、图片放哪

- **文章配图** → `content/attachments/`，正文用 `![[图片.png]]` 插入。
- **「图库」栏目的图** → `web/assets/img/gallery/`（构建自动生成缩略图，可选装 Pillow；没装则退回原图）。

---

## 六、顺序由谁决定（别找错地方）

- **顶栏顺序**：由 `web/site.config.json` 的 `nav` 数组决定，**与文件夹先后无关**。
- **帮助文档目录树的顺序 / 分组**：由 `web/site.config.json` 的 `docs.tree` 决定
  （分组写 `section` 会自动展开成该栏目全部文章；单篇写 `items: [{slug: …}]`）。
- **栏目内文章顺序**：由各篇 front-matter 的 `order` 决定。
- **栏目自身的定义**（标题 / 描述 / 目录名）：`web/site.config.json` 的 `sections` 数组。

## 七、当前尚未「严格对齐」的点（备忘）

- 单篇页在 vault 根平铺，其**摆放位置不体现导航先后**，先后只在 `site.config.json` 里体现。
- 存在**两处真相**（`site.config.json` 与 `content/` 文件夹名），靠人工同步；构建暂不做一致性校验（如需可加）。
