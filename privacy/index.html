隐私政策

本站与插件

本站是纯静态页面，不加载任何第三方脚本、不使用 Cookie、不做访问统计。

一句话总结

插件不上传你的任何数据，唯一例外是匿名使用统计（默认开启、可一键关闭，只发「随机匿名标识 + 版本号 + 日期 + 事件名」）。设置存在你自己的浏览器里；其余可能对外发出的请求，是你在「阅读洞察」里主动配置后，向微信读书官方网关（以及你主动启用 AI 增强后向你选定的国产大模型）发送的请求。

设置数据

屏占比、自动阅读速度、勿扰、全屏等偏好，通过 chrome.storage.local 保存在你自己的浏览器本地。换设备不会同步，也不会被任何人读取。

划线与想法

「笔记」功能通过 weread.qq.com 同源接口读取你自己的划线与想法，用的是你当前标签页里已有的登录态。

  • 请求只发往 weread.qq.com，不经过任何第三方
  • 内容只在内存里短暂缓存，不落盘、不上传

阅读洞察（可选，需你主动配置）

  • 需要你粘贴自己的微信读书 wrk- Key，默认只保存在本机（除非你在插件里主动启用下文的「账户与多端同步」）
  • 请求只发往微信读书官方网关 i.weread.qq.com，请求与报告都不经过插件作者的服务器
  • 报告在你本机生成；导出只是把文件存到你自己的电脑
  • 随时可以在「🔑 API Key」里删除 Key

AI 增强（国产大模型，可选，需你主动配置）

  • 报告的数字仍在你本机按固定规则算好，你选定的大模型只负责把已算好的客观数据 + 少量划线/想法原文样本写成自然语言「执行摘要」，它不算数字
  • 内置 6 家国产提供商：DeepSeek / 通义千问（阿里百炼）/ Kimi（月之暗面）/ 智谱 GLM / 豆包（火山方舟）/ 硅基流动，另可自填「自定义端点」（OpenAI 兼容）；不提供任何国外模型入口
  • 需要你粘贴自己的该家 Key，各提供商 Key 分别保存，默认只保存在本机（除非你在插件里主动启用下文的「账户与多端同步」）
  • 启用后，仅把「书架 / 累计阅读 / 笔记 / 完读 / 分类偏好 / 年度趋势」等汇总事实，以及「笔记最多几本书」的划线/想法样本（每本最多 6 条）发往你所选服务商的 baseURL；你的微信读书 wrk- Key 绝不会发给大模型
  • 未配置任何 AI Key 时，不会向任何大模型发起请求，报告退回规则化摘要
  • 随时可以在「🔑 API Key」里删除某个提供商的 Key

插件的账户与多端同步（可选，默认关闭）

浏览器插件的「🔑 API Key」面板新增了可选的「账户与多端同步」：

  • 默认关闭。不启用时，插件的 Key 行为与以往完全一致 —— 只存本机 chrome.storage.local，不上传。
  • 只有你主动启用（或在本机用账户码 / 6 位登录码登录）后，才把本机已配置的微信读书 Key 与当前所选提供商的 AI Key 加密（AES-256-GCM）后托管到同一套自建云函数，与官网、网页版共用同一个账户码：一处填写，插件 / 官网 / 网页版都能用。
  • 启用后，插件会把托管 Key 拉回本机，仍由插件后台直连官方网关 / 所选大模型（请求路径与未启用时相同，不经作者服务器中转）。这也意味着持有账户码即可取回 Key 明文，请像保管密码一样保管账户码。
  • 可随时在插件面板里「关闭同步」（本机 Key 保留、不再同步）、「清除云端 Key」（本机 Key 不受影响，其他设备将无法再同步到 Key）或「退出账户」。

官网与网页版（H5）的账户与 Key 托管

官网（/）与网页版（/app/）是同一套账户、同一个登录系统：两者在同一个域名下，共用同一个账户码与登录状态——在官网「我的账户」页登录/配置，网页版立刻生效，反之亦然。

网页版（/app/）是纯前端页面，阅读数据与人格判定全部在你的浏览器本机计算，不上传。只有下面两样东西会存到作者自建的云函数：

  • 账户码：一串随机生成的 32 位标识（不含任何个人信息），用来识别「这是同一个账户」，作用等同账号；换设备输入它即可找回同一账户。可在官网「我的账户」或网页版「我的」里查看与复制。
  • Key 与昵称：你主动粘贴的微信读书 wrk- Key / 所选国产大模型的 Key，会加密（AES-256-GCM）后托管在自建云函数，仅用于代你向微信读书官方网关 / 所选大模型发起请求；昵称是非敏感展示名，可选托管以便跨设备同步。

补充说明：

  • 服务端只回掩码，不下发 Key 明文；头像不上传图片，用昵称首字在你本机渲染
  • 「我的账户」（官网 /account/ 与网页版同款页）里可一键清除托管的 Key；「退出登录」会让本机切换为全新空账户（原账户仍在服务端，用账户码可再次登录）
  • 若未来接入微信登录，我们将只保存微信返回的匿名 openid 用于识别账户，届时会更新本页

匿名使用统计（默认开启，可一键关闭）

为了解插件是否被使用，插件每天至多向自建的统计接口（微信云函数）上报一次「活跃」。

  • 只发三样东西：① 随机匿名标识（本机生成一次的纯随机 UUID，不含任何个人信息）② 插件版本号 ③ 事件名（active）；日期由服务端记录
  • 绝不发送：阅读数据、wrk- Key、AI Key、书目、笔记内容、IP、浏览器指纹、微信读书账号
  • 服务端只存按天的聚合计数 + 随机匿名标识，保留 90 天，到期清除
  • 不引入任何第三方统计 / 广告 SDK（本统计为自建）
  • 关闭方式：插件主菜单 →「📖 阅读设置」→「📊 匿名使用统计」→ 关闭，关闭后不再上报
