## 0. 少数派发布要点（先看这段）

1. **质量优先**：少数派一篇好文胜过十篇水帖。标题、结构、配图、截图都要到位，**写成一篇真正的「体验 / 评测」长文**，别写成产品说明书。
2. **先 Matrix，后主站**：先发到 **Matrix 社区**（门槛低），质量够高会被编辑推荐上主站；也可按站内当前入口主动投稿（**以官网实际入口为准**）。
3. **写「问题 → 方案 → 取舍」**：先讲你遇到的真实麻烦，再讲怎么解决，最后讲你**为什么这么做、舍弃了什么**——少数派读者最看重「有思考」。
4. **链接放文末**：「获取方式 / 下载」区给官网与商店地址即可，正文中间不插链接。
5. **亮明身份 + 如实披露利益相关（少数派硬性要求）**：开头就说明「这是我自己做的开源项目」；**并按平台《宣传内容处理规则》，在编辑器勾选「自我宣传」、在正文显著处写明「利益相关」**——**准确披露是「被精选 / 上首页」的前提**（官方明确允许、并鼓励「高质量的自我宣传」）。

## 2. 主文 · 产品体验（首发 · 争取上主站）

**标题**：我给微信读书网页版写了个增强扩展，把它调成了「纸质书的行宽」

**副标题（可选）**：一个只作用于微信读书的浏览器扩展，配上屏占比、勿扰、笔记聚合与一套趣味「阅读人格」

**正文**：

```
一、起因：一个每天都在用、却总有点别扭的网页

我是微信读书的重度用户，但主要在电脑上用网页版看。用久了，有三个长期困扰：

1. 正文两侧留白太宽，一行字横跨整个屏幕，眼睛要来回扫，读一会儿就累；
2. 顶部工具栏常驻，读得正投入时总被那排按钮打断；
3. 划线、想法记了一堆，却几乎从不回头复习——记了等于没记。

市面上的通用样式脚本能解决一部分（比如页面的深色模式、字体大小），但它们不针对微信读书：往往需要自己写规则，还容易误伤别的网站。

后来我想，既然每天都要用，不如给自己写一套「专属」的。于是就动手做了「微信悦读」——一个**只作用于 weread.qq.com** 的浏览器扩展。写着写着功能越来越多，索性整理成一篇文章，讲讲它是怎么解决上面这三个问题的。

（说明：这是我的自用开源项目，GPL-3.0，代码在 GitHub。以下提到的功能均为已上线功能，配图都是真实界面。利益相关：本文为作者本人自荐，无赞助、无奖励。）

二、读得舒服：把阅读区调成「纸书」

这是解决第一个困扰的核心。网页版没给阅读宽度开关，我把**屏占比**做成了 50%–100% 自由调节：

· 滑块拖到 70% 左右，正文宽度接近一本纸质书，读起来明显更顺；
· 面板里还有快捷比例按钮，几十秒就能调到自己顺眼的宽度；
· 设置会自动保存，刷新、重开都在。

配合它的还有「减干扰」三件套：

· **浮动工具栏**：屏占比调大后，原生工具栏会自动隐藏，鼠标移到顶部 / 右侧才淡入，点击照常可用（翻页、滚动模式都适配）；
· **勿扰模式**：一键收掉书页以外的干扰元素；
· **全屏模式**：F 键进入全屏沉浸阅读，退出后自动恢复原来的状态。

另外加了几个快捷键，习惯之后很顺手：**空格**（自动阅读）、**D**（勿扰）、**F**（全屏）、**?**（帮助 / 调试面板）。

> 配图建议：`store-01`（屏占比）、`store-02`（沉浸）、`store-03`（勿扰）、`store-04`（快捷操作）

三、记得下来：让划线变成「能复习的东西」

第二个困扰是笔记。我的处理思路是三个动作：**聚合、清洗、复习**。

· **聚合**：一本书的所有划线与想法一键聚合，按章节分组，内置搜索框能按关键词实时定位某条；选中正文文字时，会弹出「复制」浮标。
· **清洗**：复制时自动去掉官方水印和多余格式，粘到记事本 / 微信里是干净的纯文本（也提供富文本）。
· **复习**：可以导出 Markdown / HTML / PDF；更能把笔记用**本机语音**「读」出来听——单条听、连续朗读、只听想法都行，通勤、走路、闭眼时都能复习。语音是本机合成，不联网、不上传。

> 说明：读取笔记需要先填一次微信读书的官方 API Key（存在本机）。如果你只想要「整理方法」，上面三步手动做也成立，工具只是省事。

> 配图建议：`store-07`（笔记增强 · 聚合 / 搜索 / 导出 / 朗读）、`store-06`（统计与导出）

四、看得见自己：阅读统计与一套趣味「阅读人格」

第三个困扰其实是「我到底读了多少、读成了什么样」。这部分做了两块：

· **阅读统计**：统计前台阅读时长（今日 / 本周 / 本月 / 本书），显示当前书籍进度与最近 10 本书，可一键导出 HTML / PDF / Markdown / CSV / JSON。
· **阅读洞察 + 阅读人格**：用你自己的官方数据（阅读时长、书架结构、笔记数量、阅读时段等）**在本机**生成一份「阅读行为报告」，并按四个维度算出一套趣味「阅读人格」——
  · 深潜 / 广撒、求实 / 求意、理性 / 感性、计划 / 随兴；
  · 输出一个 4 位人格代码 + 主称号 + 数据依据，可一键生成竖版分享图。
  · 需要说明：这是**纯规则 + 本机计算**，图个乐，**不是心理测评**（也不会用 MBTI® 商标名）；所有数据只在你本机算，不上传。
  · 可选接入 6 家国产大模型（DeepSeek / 通义千问 / Kimi / 智谱 GLM / 豆包 / 硅基流动）做 AI 解读；不配也完整可用。

> 配图建议：`store-11`（阅读人格界面）、`store-08`（阅读洞察报告）、以及竖版分享图 `marketing/小红书/配图-10-阅读人格分享图-1080x1440.png`

五、一些我比较在意的取舍

写这类工具，最容易被忽视、但我认为最重要的是**隐私与边界**：

· **只在微信读书里运行**：不注入别的网站，不做通用样式脚本；
· **数据存本地**：设置、标签、统计都存在浏览器本地，**不上传你的阅读数据**；笔记等读取走官方接口、Key 存在本机；
· **零外部依赖**：纯原生 JS，没有第三方库，没有远程代码；
· **权限极少**：只申请 storage 保存设置；
· **开源**：以 GPL-3.0 开源，代码可查。

唯一的一个例外要如实说明：有一个**匿名活跃统计**，每天至多上报一次「活跃」，内容仅随机匿名标识 + 版本号 + 日期 + 事件名，不含阅读数据、Key、书目、笔记；它**默认开启，但可在设置里一键关闭**。

另外还有两个小功能值得一提：

· **本地找书**：给书架书目打本地标签，支持按书名 / 作者 / 标签 / 拼音首字母（如 rzjx →《认知觉醒》）等多维度筛选；标签只存本地，**不写回微信读书**。
· **评论侧栏**：阅读页右侧可折叠的评论栏，按当前章节展示公开评论，边读边看别人的想法。

六、怎么用

· 电脑端：在 Edge 商店搜「微信悦读」即可安装（Chrome 也支持）；
· 手机端：不用装 App，浏览器打开官网的手机版，就能看阅读报告和生成「阅读人格」分享图。

七、小结

「微信悦读」解决的都是我自己每天遇到的小麻烦：读得舒服、记得下来、看得见自己——外加一条我认为不该妥协的隐私底线。它不追求大而全，只想把微信读书网页版的阅读体验往前推一点点。

## 4. 方法论长文（备选 · 干货长尾 · 软带）

**标题**：把微信读书的划线，变成能复习的知识资产

**正文**：

```
「划了很多线，却从没回头看过」——如果你也有这个毛病，这篇讲我的解法。

（利益相关：文末提到的「微信悦读」是我自己开发的开源项目，本文为作者本人自荐，无赞助、无奖励。）

一、先想清楚：划线不是目的

很多人（包括以前的我）把划线当成「读过了」的仪式。但划线本身不产生价值，只有被**翻回来、用起来**，才算数。所以「整理笔记」的本质，是让这些句子能离开书、进入你自己的知识流。

二、三个动作：聚合 → 清洗 → 复习

**1）聚合**
不要在一本书里一条条翻。先把一本书的划线、想法集中到一处，按章节排好；能搜索就更好——想到「我好像在书里记过某个概念」，一搜就能定位。

**2）清洗**
从书里复制出来的内容常带水印和格式。整理时顺手洗掉，保持纯文本，粘到任何笔记软件都干净。这一步最琐碎，但决定了你的笔记「能不能用」。

**3）复习**
笔记要能「离开书」：
· 导出成 Markdown / HTML / PDF，归档进自己的知识库；
· 或者更省事——直接听。把笔记用「朗读」放出来，通勤、走路、做家务时都能过一遍。

三、工具怎么帮上忙

## 6. 事实口径（写文案时的红线 · 以代码为准）

- 快捷键仅 `空格 / D / F / ?`（**不写 T**）。
- 语音一律「朗读 / 听」，不写「音频导出 / 导出音频」。
- 大模型只列 6 家国产（DeepSeek / 通义千问 / Kimi / 智谱 GLM / 豆包 / 硅基流动），不列国外模型。
- 隐私只说「不上传你的阅读数据」；匿名统计如实说「默认开、可关」。
- 权限只说「只用 storage」；不写「无任何权限」。
- 不出现「永久免费 / 绝对无广告」等绝对化表述（只说「开源、免费可装」）。
- 小程序「悦读且住」**每帖底部固定带一行** `· 🔍 微信小程序：微信搜「悦读且住」，不用装 App`——**未上线也写**（按「直接可用」口吻，不写「即将上线」）。
- **利益相关**：如实披露「本文为作者本人自荐（自我宣传），无赞助、无奖励」；发布时在编辑器「利益相关」处勾选「自我宣传」——**准确披露是被「精选 / 上首页」的前提**。
