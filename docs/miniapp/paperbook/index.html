我的纸书

电子书有书架，纸质书往往散在家里各处。我的纸书在小程序里给你建一个纸质书目录。

入口：「我的 → 更多 → 📚 我的纸书」。

加书：三种方式

方式怎么做适合
📷 扫码加书对准书背条码连续扫，一直扫到点左上角返回有条码的新书
🖼 拍照识码拍照或从相册选图，自动识别条码条码不清晰
✍️ 手动添加自己填书名或 ISBN没条码的旧书

只认图书条码

扫码只识别 978 / 979 开头的图书 ISBN；扫到书上别的条码会提示你重扫。

找书：搜索与筛选

  • 搜索：书名 / 作者 / ISBN / 标签
  • 筛选：全部 / 有电子版 / 仅纸质 / 已读 / 在读 / 想读

每本书都能记这些

  • 阅读状态：已读 / 在读 / 想读（再点一次取消）
  • 标签：如「一号书柜」「借出中」，最多 10 个
  • 纸质位置：例如「客厅书架第 2 层」
  • 我的感想：最多 2000 字，只存本机，与微信读书笔记分开
  • 关联电子书：把它和你微信读书里的电子版绑起来；自动匹配不准时可以手动关联
  • 关联后还能看这本书电子版的笔记明细

导出与备份

  • 导出 Markdown：把纸书目录分享成文件，或复制到剪贴板（不含 Key、不含笔记原文）；
  • 云端备份：每次改动都会静默备份到云端；换手机后进这一页点「从云端恢复备份」即可拉回。

两个小说明

  • 小程序无法唤起微信读书 App：书详情里的「去微信读书读」其实是把书名复制到剪贴板，由你自己去 App 里搜；
  • 拍照识码用的图片识别完即删除，不在云端留存。
