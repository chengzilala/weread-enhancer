# 日志规范

## 概述

本规范定义了微信读书插件开发过程中调试日志的生成、存储与分析方法，旨在建立基于日志证据的问题定位机制，减少主观猜测，提升调试效率。

## 日志生成

浏览器功能测试过程中，插件（`content.js`）会自动采集运行时日志并缓存于内存中。日志内容包括 DOM 结构快照、计算样式、状态变更记录及操作历史。

## 日志存储

- **本地存储路径**：`~/Downloads/`（macOS 浏览器默认下载目录）下
- **文件命名格式**：`weread-debug-{timestamp}.json`
- **获取方式**：通过插件调试面板的「下载日志」或「复制日志」按钮导出

## 日志分析方法

1. **定位最新日志**：按文件修改时间降序排列，取最新生成的文件进行分析
2. **日志分析原则**：以日志中记录的 DOM 结构、计算样式和状态数据为唯一证据，避免脱离数据的无端猜测
3. **分析闭环**：读取日志 → 定位根因 → 修改代码 → 重新测试 → 验证修复效果
