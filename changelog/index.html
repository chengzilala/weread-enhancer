v0.28.0 · 2026-10-11

AI 增强不再只认 DeepSeek，可自选国产大模型。

  • 多模型支持：「🔑 API Key」里的「AI 增强」区新增提供商下拉 + 模型名输入，内置 6 家国产大模型——DeepSeek（默认）/ 通义千问（阿里百炼）/ Kimi（月之暗面）/ 智谱 GLM / 豆包（火山方舟）/ 硅基流动，只用国产、不列任何国外模型
  • 各 Key 分别保存：各家 Key 分开存，下拉来回切换不会丢；「生成 AI 解读」用的就是你当前选中的那家
  • 新增「测试连接」按钮：只校验不保存，先确认 Key 能用再存
  • 自定义端点：可填任意 OpenAI 兼容的 baseURL（覆盖 MiniMax / 阶跃星辰 / 百度千帆等），首次使用按需申请该域名权限
  • 无感升级：原来的 DeepSeek Key 会自动迁移过来，DeepSeek 保持默认，行为不变
  • 权限：内置 5 家新增明确域名（不用通配）；自定义端点走可选权限、用到才授权

图标换成「蓝底白 W」，四个端互相找得到。

  • 品牌图标统一：全端图标改为蓝底白 W 圆标；插件右下角浮动按钮同步改成 44px 圆形蓝底白 W，与插件图标、小程序头像、商店展示图完全一致
  • 四端互联：插件官网 / 网页版（H5）/ 微信小程序 / 作者个人网站，四个端都加了互相的入口——网页版与小程序里可一键复制另外几端的网址（含小程序码，微信内不能直接开网页故用复制的方式），官网页脚新增「个人网站」
  • 官网首页改版：四个入口按钮下各加一行常显小字说明「这是什么、什么时候用」，鼠标悬停还能看到更完整的解释
  • 网站标题字体：标题换用手写体「芝麻行」子集（随包附带开源许可文件）
  • 支持中心：默认页签由「打赏」改为「反馈」
  • 一并包含（此前已提交、未单独发版，均属网页版 / 小程序侧）：阅读文字大小四档、外观明暗主题（跟随系统 / 浅色 / 深色）、阅读报告表格排版修复

找书一键直达：主页就能打开，搜索体验重排。

  • 「▶ 听」新增朗读声音自选：面板底部常驻「🔊 朗读声音」下拉 + 「▶ 试听」，选择即生效并记住
  • 找书原有的「导出 / 导入 JSON」按钮移出，统一并入主菜单「🗄️ 数据备份」

v0.25.0 · 2026-10-07
