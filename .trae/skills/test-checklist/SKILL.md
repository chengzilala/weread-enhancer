# 生成验收测试清单

## 使用场景
某功能刚开发完，要在合并/发版前做人工验收。

## 指令
1. 按功能子项分组，用 `- [ ]` 勾选项逐条写，编号（1.1 / 1.2…）。
2. **必须覆盖的边界项**（易漏，务必包含）：
   - 输入框内触发不误伤（如空格/字母键在输入框里只输入字符）
   - 合成事件 `isTrusted=false` 不触发功能
   - `Ctrl/Alt/Meta` 组合键不误触发
   - 刷新后持久化状态保持
   - 多功能协同互不打断
3. 产出到 `test/{{功能}}测试清单.md`。

## 示例（片段）
```
## 二、Space 自动阅读
- [ ] 2.1 按空格 → 开始，UI 同步变"暂停"
- [ ] 2.2 运行中按空格 → 暂停
- [ ] 2.3 输入框内按空格，不触发（仅输入空格字符）
```
