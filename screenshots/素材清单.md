## 二、生成流水线（改图只需跑两条命令）

```
tools/autoshot.py  →  screenshots/auto/*.png   （真实界面母版，登录后自动抓）
                          │
                          ▼
       promo.py  →  screenshots/promo/   （GitHub）
                 →  screenshots/store/   （Edge / Chrome 微软系·全量母版）
                 →  release/微软商店-上传/ （微软槽位分好的上传包）
                 →  release/360-素材/     （360）
```

```bash
# 1) 抓真实界面（首次先 --login 登录，之后每次带一本书的网址）
python3 tools/autoshot.py --login
python3 tools/autoshot.py --url "<你在读的某本书的网址>"

# 2) 出全部展示图（Banner + 卡片 + 磁贴 + 商店截图 + 360 效果图）
python3 promo.py
```

## 七、微软 Partner Center 上传对照（来自官方要求）

上传包在 `release/微软商店-上传/`，**已按槽位分好文件夹**，拖到对应槽位即可：

| 槽位（Partner Center） | 规格 | 数量 | 上传包位置 |
|---|---|---|---|
| 扩展徽标 | 300×300（最小 128×128，1:1） | 1 | `1-扩展徽标-300x300/` |
| 小促销磁贴 | 440×280 | 1 | `2-小促销磁贴-440x280/` |
| 大促销磁贴 | 1400×560 | 1 | `3-大促销磁贴-1400x560/` |
| 屏幕截图 | **精确** 1280×800 或 640×400 | **最多 6 张** | `4-屏幕截图-1280x800-最多6张/` |
| YouTube 视频 URL | 可选 | 0–1 | 不提供 |
| 搜索词 | 每个 ≤30 字符，累计独立词 ≤21 个 | ≤7 | **中文 listing：** 微信读书 / 屏占比 / 阅读辅助 / 笔记导出 / 阅读统计 / 阅读人格 / weread；**英文 listing：** wechat reading / weread / reading enhancer / reading extension / reading width / reading stats / book notes |

**截图取哪 6 张**（顺序即上传顺序，见 `promo.py` 的 `MS_SCREENSHOTS`）：
1. 屏占比自由调节　2. 沉浸式阅读　3. 快捷操作　4. 阅读统计与导出　5. 笔记增强　6. 阅读人格 MBTI

> ⚠️ **常见报错**：把 `promo-440x280.png`（小磁贴）传进「屏幕截图」槽 → 报「文件大小不正确」。磁贴与截图是两个槽，别放错文件夹。
> ℹ️ 截图全量母版在 `screenshots/store/`（共 11 张）；想换这 6 张的选法，改 `MS_SCREENSHOTS` 后重跑 `python3 -c "import promo; promo.build_ms_upload()"`。
> ℹ️ 扩展徽标由矢量母版 `assets/logo.svg`（蓝圆 + 白 W）光栅化而来，任意尺寸都清晰；logo 要改就改这个 SVG，重跑 `promo.py` 即可。
> ℹ️ 同一套也适用于 Chrome 网上应用店（截图上限 5 张，取前 5 张即可）。
