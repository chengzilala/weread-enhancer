阅读人格是什么

「阅读人格」是插件「🪞 阅读洞察」里的首屏：它不看问卷，而是从你真正读过的书、划过的线、写下的想法里，把你这个人推出来。结果是一个 4 位字母代码 + 一个主称号（16 型「读书人」之一），全部在你本机计算。

先说明它是什么

这是一份基于阅读行为数据的趣味性参考画像，参考了 MBTI 的四维结构，但不是心理测评，也不构成专业性格鉴定；对外不使用 MBTI® 商标，阅读人格代码和 MBTI 码也不是一回事。

一、它为什么有意思

读过的书是一面没有滤镜的镜子：你买了什么、读完了什么、在哪里划线、写了什么想法，比任何问卷都诚实。「阅读人格」做的事，就是把这些行为归纳成四个维度、再拼成一个具体的人。

和「知识资产」那一栏互补——那边讲「怎么读」，这边讲「你是谁」。

二、怎么生成

  1. 在「🔑 API Key」里配好 wrk- Key（见 API Key 使用说明）
  2. 打开「🪞 阅读洞察」→ 报告首屏「🧬 我的阅读人格」
  3. 点「📊 启用分析」——这时才读取你笔记最多几本书（最多 5 本）的划线 / 想法，在本机判定，生成人格卡与词语分析
  4. 想要更自然的文案，再点「🤖 生成 AI 解读」（可选）

不点按钮就不联网、不消耗请求；数据不够时先告诉你还差多少：累计 ≥10 小时 且笔记 ≥20 条 才会生成，否则显示「还差一点数据」的引导态。

三、代码怎么读

代码形如 DFLP，四位依次是下面四维的结果。每一维都在「左右两极」里二选一；某一维数据不足时，那一位显示 –（例如 DF–P），并说明「这一维数据还不够」。

位置维度左极右极主要看什么
第 1 位阅读能量D 深潜B 广撒单本均摊时长、书架前 3 类集中度、电子书完读率、同时在读的书数
第 2 位内容取向F 求实M 求意官方偏好分类（按阅读时长）/ 书架分类（按本数）落在「求实组」还是「求意组」
第 3 位表达方式L 理性E 感性你的划线 / 想法里，逻辑词与情感词的占比（辅以问号 / 感叹号）
第 4 位阅读节奏P 计划R 随兴有阅读的统计单元占比 + 波动系数：越规律越偏 P

怎么读你的代码

把四个字母拆开读就行。例如 DFLP = 深潜 · 求实 · 理性 · 计划：读得深、偏好实用、习惯分析、按计划推进。四个字母合起来，才对应 16 型图鉴 里的那一个称号。 每一维的判定依据与阈值，见 四维详解。

四、四个族群

四位字母的前两位（能量 × 取向）把 16 型分成 4 个族群，一眼看出读书的大方向：

族群含义一句话
DF深潜 · 求实读得深，且要能用得上
DM深潜 · 求意读得深，为的是想明白
BF广撒 · 求实读得广，实用为先
BM广撒 · 求意读得广，跟着意义走

每个族群下各 4 型，共 16 型，见 16 型图鉴。
