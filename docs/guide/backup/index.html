数据备份与恢复：本机数据一键备份

插件的数据都只存在你自己的电脑上。换电脑、清浏览器缓存之前，先来这里备份一份，否则会永久丢失。

从哪打开

悬浮球 → 菜单 → 🗄️ 数据备份。

备份哪些数据

面板顶部「本机数据一览」列出的这几类，就是会被打包的内容：

数据是什么
找书标签本地找书 里你给书打的标签、分组
阅读统计阅读统计 累计的时长等本地记录
插件设置屏占比、自动阅读、勿扰等各项偏好
新手引导版本记录引导看到哪一版，避免重复弹出

没数据的项会显示「暂无」并置灰。

导出

点 ⬇️ 导出备份，会下载一个 JSON 文件，文件名形如 微信悦读-数据备份-20261008.json。

备份文件不含 Key

出于安全，备份文件里没有任何 API Key（wrk- / sk-）。换设备时请重新粘贴一次 Key，见 API Key 使用说明。

导入（两种模式）

点 ⬆️ 导入（合并） 或 ⬆️ 导入（覆盖），选一个之前导出的 JSON：

  • 合并：把新数据并进现有数据。标签按本本书合并去重、统计按天累加、设置逐项合并、引导版本取较大的那个。适合同步两台设备各自的阅读。
  • 覆盖：先清空本机这四类数据，再整份写入备份文件。适合「换电脑后完整还原」。

导入只有在文件确实是本插件导出的（带 app 标识与 schemaVersion）时才会成功，否则会提示无效文件。

导入或清空之后，面板会出现 🔄 刷新页面以加载最新数据，点一下让各模块重新读取。

清空本机用户数据

面板底部危险区有 🗑️ 清空本机用户数据：相当于重置插件数据，会清掉上面四类内容，需二次确认、不可撤销。动手前建议先导出一份备份。
