语音复习：把笔记读出来

书读完了，划线留下了一堆，可眼睛实在不想再看屏幕。这个功能把它们读出来——通勤路上、躺着闭眼时也能复习。

入口在「笔记」面板里

「语音复习」没有单独的菜单项，它就藏在 笔记增强 的「📝 笔记」面板里：

  • 每条笔记右上角有个小圆按钮 ▶，点一下读这一条；再点一次暂停 / 继续。
  • 面板工具栏有三个按钮：▶ 连续朗读（按当前列表顺序一条条读）、▶ 听全部（把本书划线+想法排队读）、▶ 只听想法（只读你自己写的批注）。
  • 面板底部有朗读控制条：⏮ / ⏸ 暂停 / ⏭ / ⏹ 停止，以及计数「第 N / 共 M 条」。

声音可以自己挑

底部常驻一条「🔊 朗读声音」：下拉里能选浏览器（系统）里可用的语音，点 ▶ 试听 听一句再决定。默认是「自动」——优先挑本机的普通话声音。

选过的声音会记在本机，下次打开还是它。

边界说明（重要）

  • 本机合成、不联网、不上传：用的是浏览器自带的语音引擎，声音在你的电脑上生成，插件不发送、不保存任何内容。
  • 不导出音频：这里只做「当场朗读」，不生成 mp3，也没有下载按钮。
  • 语速 / 音调 / 音量固定，不可调（保持一致的听感）。
  • 只读你自己的笔记：划线、想法——不朗读正文。
  • 不自动翻页：朗读时只会把当前这条滚到可见区域，不会替你翻书。
  • 切走就停：切到别的标签页或关掉页面，朗读立即停止，不会在后台偷播。
  • 浏览器太老、不支持本机语音时，「听」相关按钮会自动隐藏。

为什么不做「听书」

这是复习笔记，不是把整本书念成有声书。所以文案只用「朗读 / 听」，不做电台式的听书功能。
