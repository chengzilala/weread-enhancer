# 阶段十一 笔记增强（v0.10.0） — 测试验收清单

> 前置：扩展管理页「重新加载」插件 → 打开一本书的阅读页（`weread.qq.com/web/reader/…`）→ 悬浮球展开主菜单。
> 排错统一看控制台 `[notes]` 开头日志。

## 一、菜单入口与面板

- [x] **1.1** 主菜单里出现「📝 笔记」项（在「阅读统计」之后）
- [x] **1.2** 点击「📝 笔记」，弹出面板，标题为「📝 笔记」
- [x] **1.3** 面板顶部显示 `《书名》 · 划线 N 条 · 想法 N 条`
- [x] **1.4** 面板上有「刷新」「复制笔记」「导出 Markdown」「导出 HTML」「导出 PDF」「导出纯文本」六个按钮（窄窗口下自动换行，不溢出）
- [x] **1.5** 有「划线 N」「想法/批注 N」两个 Tab，默认停在「划线」
- [x] **1.6** 暗黑 / 护眼主题下面板颜色跟随 `--wre-*` 变量，无残留刺眼白底

## 二、数据加载（接口优先 + DOM 兜底）

- [x] **2.1** 已登录且有划线：面板正确列出划线，按章节分组，章节标题在上
- [ ] **2.2** 点「刷新」能重新拉取（相同时段命中 5 分钟内存缓存，属预期）
- [ ] **2.3** 未登录（或登录态失效）：面板给出「请先登录后重试」类提示，不空白不报错
- [ ] **2.4** 该书没有划线/想法：显示对应空态（「这本书还没有划线～」/「这本书还没有想法/批注～」）
- [ ] **2.5** 接口不可用时，回退抓取页面已渲染的划线，面板仍能列出内容
- [ ] **2.6** 非阅读页（如书架页）点笔记：给出「请先打开一本书」类提示
- [ ] **2.7** 官方网关取笔记：日志出现 `[notes] 官方网关取笔记完成`；若直连失败会先出现 `官方 bookId 反查结果` 再用反查到的 ID 重试成功
- [ ] **2.8** 想法条数多于 20 条的书：面板条数与微信读书 App 内该书想法总数一致（验证分页没有截断）
- [ ] **2.9** **未配置** `wrk-` Key：点开笔记面板直接进入「引导态」（**不再**回退页面抓取），显示「🔑 需要先配置 API Key」与「⚙️ 去配置 Key」按钮
- [ ] **2.10** **Key 有效**但官方网关临时失败：回退页面抓取，数据来源警示条为「页面抓取（可能不完整）」且条上有「去设置检查 Key」按钮

- [ ] **3.4** 顶部有搜索框（placeholder「搜索划线 / 想法内容…」），位于工具栏与 Tab 之间

## 三·一、搜索定位（v0.12.3）

- [ ] **3A.1** 在「划线」Tab 输入关键词，列表实时过滤为命中条目；下方显示「找到 N 条匹配」
- [ ] **3A.2** 关键词命中章节名：该章节整组（含组内全部条目）都保留显示
- [ ] **3A.3** 关键词只命中某条正文/摘要：仅该条显示，所在章节只显示命中条目
- [ ] **3A.4** 输入不存在的关键词：显示「没有找到包含『xx』的划线」空态，不出错
- [ ] **3A.5** 切到「想法/批注」Tab，同样可搜索想法（摘要 + 正文都能命中）
- [ ] **3A.7** 点搜索框右侧「×」清空，列表恢复全量；搜索词为空时「×」不显示
- [ ] **3A.8** 关闭面板再打开，搜索框恢复为空、列表为全量

## 四、批量导出（9.2.2）

- [ ] **4.1** 点「导出 Markdown」，下载 `.md` 文件，顶部为 `# 《书名》读书笔记`，含导出时间与统计
- [ ] **4.2** Markdown 内划线按章节分组；有想法时输出「想法与批注」小节（无想法则不输出该小节）
- [ ] **4.3** 点「导出纯文本」，下载 `.txt` 文件，含 `【划线】`/`【想法与批注】` 分区
- [ ] **4.4** 数据还没读出来时点导出：Toast 提示「还没有可导出的笔记…」，不生成空文件
- [ ] **4.5** 导出成功后 Toast 提示「已导出 Markdown」/「已导出纯文本」
- [ ] **4.6** 点「导出 HTML」，下载单文件 `.html`：双击用浏览器打开，有绿色标题条 + 概览卡片（划线/想法/覆盖章节）+ 按章节分段，样式与「阅读统计」报表一致；**无外部依赖**（断网也能正常显示）
- [ ] **4.7** 点「导出 PDF」，新窗口打开打印视图并自动唤起打印对话框；在对话框里选「另存为 PDF」得到带样式的 PDF（A4、条目不被跨页截断、卡片与绿色主色保留）
- [ ] **4.8** 若浏览器拦截了新窗口：Toast 提示「浏览器拦截了新窗口…」，日志有 `[notes] PDF 导出被拦截`，不静默失败
- [ ] **4.9** 点「复制笔记」，Toast 提示「已复制笔记（可直接粘贴）」；粘贴到飞书/Word/公众号编辑器保留排版（富文本）；粘贴到**记事本 / 微信**得到「干净纯文本」——**不含** `#` `*` `>` 等 Markdown 符号，格式为「《书名》读书笔记 + 【划线】/【想法与批注】+ [章节] + 序号」
- [ ] **4.10** 剪贴板无 `ClipboardItem` 支持时点「复制笔记」，回退纯文本复制，Toast 提示「已复制笔记（纯文本）」
- [ ] **4.11** 划线/想法超过一屏时，导出的 HTML/PDF 内容完整（与面板条数一致）；想法多于 20 条的书写法见「二、数据加载」的分页校验

## 五、选中即复制 + 水印清洗（9.2.1）

- [ ] **5.1** 在正文里用鼠标选中一段文字，松手后选区上方出现「📋 复制」浮标
- [ ] **5.2** 点浮标复制，Toast 提示「已复制」；粘贴出来与选中的正文一致
- [ ] **5.3** 复制到的内容**不含**官方版权声明/水印（如「——微信读书」「来自微信读书」等）
- [ ] **5.4** 用键盘 Ctrl/Cmd+C 复制选中正文，粘贴内容同样已去水印
- [ ] **5.5** 选中内容为空 / 极短时不弹浮标（不打扰）
- [ ] **5.6** 点击页面其他位置，浮标自动消失

## 六、Key 必选与一键跳转设置（v0.12.1）

- [ ] **7.1** 未配置 Key 时打开笔记面板：进入「引导态」，**不**再尝试网页接口 / 页面抓取（日志出现 `[notes] 未配置官方 API Key，拦截笔记读取并引导去配置`）
- [ ] **7.2** 引导态点「⚙️ 去配置 Key」：笔记面板关闭，「☁️ 官方数据」面板打开且停在「⚙️ 设置」页
- [ ] **7.3** 在设置页粘贴有效 `wrk-` Key 保存后，回到「📝 笔记」能正常读取（引导态消失）
- [ ] **7.4** 引导态点「我已配置，重新检测」：重新检查 Key 状态并刷新（已配置则直接出数据；未配置仍停留在引导态）
- [ ] **7.5** Key 已失效（后台返回 `code:'auth'` 或 `'nokey'`）：面板进入「⚠️ API Key 已失效」引导态，日志出现 `[notes] 官方 API Key 失效…`；**不**触发 bookId 反查重试
- [ ] **7.6** 从「官方数据 → 设置」清除 Key 后，再打开笔记面板：回到「需要先配置 API Key」引导态
