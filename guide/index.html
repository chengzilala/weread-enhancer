  • 数据备份与恢复：本机数据一键备份

  • 屏占比调节：让正文更宽

    50%–100% 自由调节正文宽度，配合屏占比过高时的工具栏浮动，把屏幕还给文字。

  • 自动阅读：让页面自己翻

    速度可调、方向可切换的自动翻页，空格键开始与暂停，适合边吃边读或跟读节奏固定的书。

  • 快捷键：四个键管住全部

    空格（自动阅读）、D（勿扰）、F（全屏）、?（帮助面板），中文输入法下也能正常触发。

  • 阅读统计与导出

    今日 / 本周 / 本月 / 本书阅读时长，当前进度与最近 10 本书，一键导出 HTML / PDF / Markdown / CSV / JSON。

  • 笔记增强：划线与想法一键留存

    按章节聚合本书全部划线与想法；支持 Markdown / 纯文本导出；选中正文即弹出复制浮标并自动清洗水印。

  • 阅读洞察：阅读行为报告 · 书架 · 发现

    粘贴你自己的微信读书 API Key，纯本地生成官方口径的阅读行为报告；还能看书架、搜书、看书评与推荐。数据不上传。

  • API Key 使用说明：阅读洞察与 AI 的钥匙

    两把 Key（wrk- 官方 / 国产大模型）的获取、配置、校验、清除与隐私红线；只存本机、不上传。

  • 阅读人格（插件里怎么用）

    插件「🪞 阅读洞察」首屏的用法：怎么点出 4 位人格代码与 16 型称号、结果里有什么、怎么分享。四维与 16 型的详细解读见「阅读人格」栏目。

  • 语音复习：把笔记读出来

    用浏览器本机语音把本书的划线与想法读出来，支持连续朗读与只听想法；本机合成、不联网、不上传、不导出音频。

  • 本地找书：给书架补上标签与搜索

    用本机标签 + 多维度搜索（书名/作者/标签/状态/笔记数/最近阅读，支持拼音首字母）快速找到书架里的书，还能检索划线与想法正文。

  • 数据备份与恢复：本机数据一键备份

    把本机分散在各模块的数据（找书标签、阅读统计、插件设置、引导版本）汇总导出为一份 JSON，可再合并或覆盖导入恢复。
