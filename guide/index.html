功能教程

按插件模块分篇，一篇讲清一个功能怎么用、什么时候用。

每个功能独立成篇：先讲它解决什么问题，再讲怎么操作，最后讲常见坑。

  • 屏占比调节：让正文更宽

    50%–100% 自由调节正文宽度，配合屏占比过高时的工具栏浮动，把屏幕还给文字。

  • 自动阅读：让页面自己翻

    速度可调、方向可切换的自动翻页，空格键开始与暂停，适合边吃边读或跟读节奏固定的书。

  • 快捷键：四个键管住全部

    空格（自动阅读）、D（勿扰）、F（全屏）、?（帮助面板），中文输入法下也能正常触发。

  • 阅读统计与导出

    今日 / 本周 / 本月 / 本书阅读时长，当前进度与最近 10 本书，一键导出 HTML / PDF / Markdown / CSV / JSON。

  • 笔记增强：划线与想法一键留存

    按章节聚合本书全部划线与想法；支持 Markdown / 纯文本导出；选中正文即弹出复制浮标并自动清洗水印。

  • 官方数据：阅读行为报告

    粘贴你自己的微信读书 API Key，纯本地生成官方口径的阅读行为报告（时长、天数、日均、环比、分布、读得最多）；数据不上传。

  • API Key 使用说明：官方数据与 AI 的钥匙

    两把 Key（wrk- 官方 / sk- DeepSeek）的获取、配置、校验、清除与隐私红线；只存本机、不上传。
