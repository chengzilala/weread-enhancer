## 归档约定

1. 移入时**保留原文件名**，目录名用 `主题-年月`，便于回溯。
2. 归档不动 `git` 历史；需要时直接 `git log -- <文件>` 查原始上下文。
3. **不往这里放**：运行必需文件、构建产物（`web/dist`）、上架素材（`release/` 由 `promo.py` 生成）、含密钥/身份证号的文件。
4. 归档前先在本文件表格补一行，写清「为什么可以归档」。
