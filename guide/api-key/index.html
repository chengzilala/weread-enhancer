API Key 使用说明：阅读洞察与 AI 的钥匙

插件里有两个功能要读「你自己的」微信读书数据：阅读洞察（阅读行为报告）、笔记的划线/想法。要拿到这些，得用你自己的 API Key。本篇把两把 Key 一次讲清：怎么来、怎么配、怎么删、有什么风险。

适用插件 v0.17.0（以代码为准）

一、Key 是什么，为什么需要

  • 微信读书官方 API Key（wrk- 开头）：插件拿它走微信读书官方网关（i.weread.qq.com）读取你自己的阅读数据。「阅读洞察」的报告、书架、搜书 / 书评 / 推荐，以及「笔记」的划线/想法都依赖它。
  • 它不是插件账号，也不需要注册。它本质等于你账号的读取权限，所以必须只放在你自己这台电脑上。

一句话记住

Key 等于你账号的读取权限。只放本机，不发给任何人，不贴到聊天 / 截图 / 仓库。

二、怎么获取（wrk- Key）

  1. 打开微信读书 App → 底部「我」 → 右上角「设置」
  2. 在设置列表里找到并进入「微信读书 Skill」：

  1. 进来后往下拉，看「快速配置」区。第 ② 步就是「获取 API Key」；第 ① 步的安装指令是给 AI 助手装 Skill 用的，插件这里用不到：

  1. 点「复制 Key」，就得到一段 wrk- 开头的 Key。它默认打码显示，点右侧「👁」可看明文；同一页还有「重置 Key」，需要时可换一把新的：

顺带一看

这个页面顶部的「Skill 能力」列了它对外提供的能力（查看书架 / 阅读统计 / 导出笔记 / 搜索书籍 / 书籍简介 / 好书推荐）——插件里的「阅读洞察」「笔记增强」读的就是这些数据。

三、怎么在插件里配置

  1. 点插件悬浮球 → 菜单 →「🔑 API Key」
  2. 把 wrk- Key 粘进输入框（默认是掩码，点「显示」可看明文）
  3. 点「保存并校验」

「保存并校验」会先探一下网关连通性，再用一个需要登录的轻量接口确认真实有效，通过后才写入。

面板里能看到的按钮与状态：

按钮作用
显示 / 隐藏切换输入框明文 / 掩码
保存并校验校验通过才保存
清除 Key删除本机保存的 Key
刷新状态重新拉取当前状态

状态字段：已配置 / 未配置 · 保存时间 · 最近校验时间 · skill 版本。

四、可选：国产大模型 Key（AI 增强）

  • 可选项，不配不影响其它功能。支持内置 6 家国产提供商：DeepSeek / 通义千问（阿里百炼）/ Kimi（月之暗面）/ 智谱 GLM / 豆包（火山方舟）/ 硅基流动，另可自填「自定义端点」（OpenAI 兼容）。不提供任何国外模型入口。
  • 作用：让「阅读洞察」报告的「执行摘要」「人性化人格分析」「阅读人格润色」由你选定的大模型生成；数字仍然由本机规则计算，不交给 AI 算。不配则用默认的规则化摘要。
  • 配置位置：同一个「🔑 API Key」面板里的「AI 增强（国产大模型，可选）」区——选提供商 →（自定义需填 baseURL）→ 填模型名（已预填该家默认，可改）→ 粘贴该家 Key → 点「保存并校验」。也可先点「测试连接」只校验不保存。
  • 各家的 Key 分别保存，下拉来回切换不会丢；切换后「生成 AI 解读」用的就是你当前选中的那家。
  • 平台差异（如通义 compatible-mode/v1、智谱 /api/paas/v4、方舟 /api/v3）由各自 baseURL 吸收，你只要填对 Key 即可。

隐私必须知道

启用后，点「生成 AI 解读」时会把「笔记最多的几本书」的划线 / 想法原文样本发送给你所选提供商的接口用于生成文字。介意就别配，不影响其它功能。

五、隐私与安全（红线）

  • Key 只存在本机 chrome.storage.local：官方 Key 存 wreOfficialSkill，大模型各家 Key 存 wreAiProviders（默认 DeepSeek；旧版单键 wreDeepSeekKey 会自动迁移进来），当前选中项存 wreAiActive，不上传（大模型例外见上）。
  • 插件日志只输出掩码（形如 wrk-****(36)），不打印明文。
  • 官方提醒：Key 等同账号读取权限，请勿粘贴到聊天、截图或提交到代码仓库；怀疑泄露可在 App 里重置。
  • 不要把 Key 发给任何人，包括「帮你配置」的人。
