# 会话交接

## 使用场景
长任务中途、上下文快满、或要开新会话接着做时。

## 指令
产出 `plan/session_handoff_{{任务}}.md`，包含且仅包含：
1. **版本 / 优先级**：当前版本号、本次重点。
2. **本会话已完成**：编号清单（简明）。
3. **下一步**：每条标注**谁做**（用户手动 / AI）与**是否需确认**。
4. **关键文件路径表**：文件 → 绝对/相对路径。
5. **红线提醒**：本任务易错点。

要求：能被**整段复制**直接喂给新会话；不含密钥/隐私；不贴长代码（给路径）。

## 完成判据
新会话只读这一份就能无缝接手，不需追问背景。
