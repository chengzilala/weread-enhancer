## v0.27.1 · 2026-10-08

图标改用矢量母版重制，更清晰。

- 扩展图标（16 / 48 / 128）与小程序头像改由矢量母版 `assets/logo.svg` 光栅化重出，小尺寸下更锐利、边缘更干净
- 品牌图标此后只需维护一份矢量母版，改它后重跑打包脚本即全部刷新

## v0.27.0 · 2026-10-08

找书新增「按官方分组」封面网格（插件 / 网页版 / 小程序三端统一）。

- 「🔎 找书」新增工具条开关「按官方分组」（账号有官方分组时才出现）：列表下方按分组铺开**封面网格**（每组前 12 本 + 「还有 X 本」，末尾「未分组」），更接近官方书架；原有「官方分组」筛选与书卡灰胶囊保留不变
- 网页版与小程序「按官方分组」同样改为**三列封面网格**（组标题 + 组内数量保留）
- 网页版 / 小程序**账户打通**：新增扫码绑定（二维码为本地生成，零外部依赖），也可先由小程序生成账户码、再到网页端粘贴统一

## v0.26.0 · 2026-10-07

找书一键直达：主页就能打开，搜索体验重排。

- 新增「主页找书入口」：微信读书**主页**的「继续阅读」栏、官方「我的书架」**左侧**注入「🔎 找书」按钮，点一下就打开找书面板，不用再进插件菜单里翻
- 找书面板改版：以**大搜索框**为主角（打开自动聚焦），结果卡片去掉常驻边框、改为悬浮高亮，书名**高亮命中的关键词**
- 「📝 笔记」点击某条划线 / 想法，恢复**跳回原文并高亮**（想法优先定位它引用的原文）
- 「▶ 听」新增**朗读声音自选**：面板底部常驻「🔊 朗读声音」下拉 + 「▶ 试听」，选择即生效并记住
- 找书原有的「导出 / 导入 JSON」按钮移出，统一并入主菜单「🗄️ 数据备份」

## v0.25.0 · 2026-10-07

新增「🗄️ 数据备份」：本机数据一键导出 / 恢复。

- 新增主菜单「🗄️ 数据备份」入口：把本机**用户数据**（找书标签 / 阅读统计 / 插件设置 / 引导版本）一处汇总，一键**导出成 JSON 到本地**，也能再导入恢复（合并 / 覆盖）；**纯本机、不联网、不含任何 Key**
- 修复找书搜索：打开面板不再残留上次关键词；重绘时保留搜索框**焦点与光标**，中文组词输入不再被打断
- 找书计数口径厘清：区分「命中 X 本」与「共 Y 本」，按钮「搜索正文」改名「搜我的划线 / 想法」

## v0.24.0 · 2026-10-06

笔记新增「▶ 听」：用语音复习自己的划线 / 想法。

- 在「📝 笔记」面板就地朗读**你自己的**划线 / 想法：单条朗读、连续朗读、听全部、只听想法，底部带播放控制条
- 采用**浏览器内置语音合成**（本机合成、不上传、不联网），**零依赖、零成本、不新增任何权限**
- 支持暂停 / 继续 / 停止与朗读进度高亮；与「搜索」联动时按当前筛选结果朗读

## v0.23.0 · 2026-10-06

新增**匿名使用统计**（为移动端「运营看板」提供插件使用量）。

- 每天**至多上报一次**「活跃」，内容仅「随机匿名标识 + 版本号 + 日期 + 事件名」，**绝不包含**阅读数据 / Key / 书目 / 笔记 / IP
- **默认开启**，可在「📖 阅读设置 → 📊 匿名使用统计」**一键关闭**；关闭后立即停止上报
- 为自建统计接口（微信云函数）新增 `https://*.tcloudbase.com/*` 主机权限；统计不使用任何第三方 SDK
- 隐私政策（本机 / 仓库）已同步更新

## v0.20.1 · 2026-10-06

找书「含划线 / 想法正文」检索改为一键开始。

- 「🔎 找书」勾选「含划线 / 想法正文」原本需两步操作、容易被漏掉；现在点搜索即**自动打开该开关再检索**，一步到位
- 本次为交互修复，其余功能不变

## v0.20.0 · 2026-10-05

新增「🔎 找书」：给书架补上官方没有的标签与多维度搜书。

- 在插件内自建**本地标签层**（只存浏览器本地，**不写回**微信读书、不上传），可给书架每本书打多个标签，输入即联想已有标签
- 支持按**书名 / 作者 / 标签（多标签 AND·OR）/ 拼音首字母**（如 `rzjx` →《认知觉醒》）**/ 笔记数量区间 / 阅读状态 / 最近阅读时段**实时筛选
- 可勾选「含划线 / 想法正文」，在**你自己的划线与想法正文**里检索「我曾在哪本书里记过这个词」（单本按需拉取、仅主动搜索时取）
- 书架卡片显示封面缩略图与阅读进度条；标签支持重命名 / 删除 / 合并，并可一键**导出 / 导入 JSON**（合并 / 覆盖），防清缓存或换设备丢标签
- 拼音首字母表为**离线内置**，零依赖、不联网、不新增浏览器权限

## v0.19.1 · 2026-10-05

扩展支持中英双语。

- 新增中英文语言包，非中文浏览器下显示英文名称与简介；功能与中文版一致

## v0.19.0 · 2026-10-04

「🧬 我的阅读人格」分享图新增「人物插画」。

- 16 型阅读人格各配一位**公共领域文化名人**：牛顿、达·芬奇、达尔文、阿基米德、康德、图灵、苏轼、李白、爱迪生、马克·吐温、李时珍、莫扎特、亚里士多德、蒙田、安徒生、莎士比亚
- 插画为本项目**自绘线描图**，随插件内置，**运行时不联网、不使用真人照片**（均为公共领域人物，非宗教、非政治）
- 分享图**顶部**新增人物插画（配人物名 + 呼应小字）；报告人格卡与 HTML / Markdown 导出也同步显示代表人物

## v0.18.0 · 2026-10-04

「☁️ 官方数据」新增「🧬 我的阅读人格」，并把分析与 AI 解读改为手动触发。

- 报告首屏新增「🧬 我的阅读人格」（读书人版）：读取你读得最多几本书（最多 5 本）的划线 / 想法，在本机做四维判定 + 16 型称号 + 词语分析，并可生成手机版分享图
- 「启用分析」与「AI 解读」改为**手动触发**：打开报告不再自动拉语料、不再自动调用 DeepSeek，点按钮才联网，更省请求与 token
- 修复书架 / 搜书 / 推荐里的跳转：点书名改为在新标签打开**网页版书籍详情页**（电脑可直接打开），不再跳只能手机打开的 App 链接

## v0.17.0 · 2026-10-04

「☁️ 官方数据」新增「📚 书架」与「🔍 发现」两个页签。

- 新增「📚 书架」：一眼看全书架（电子书 / 专辑 / 公众号数量汇总），分区列表展示封面、作者、阅读进度与来源，支持「显示更多」分页
- 新增「🔍 发现」：搜书（找书 / 泛搜 / 网文 / 听书 / 作者 / 全文 / 书单 / 公众号 / 文章多种范围，支持翻页）、推荐、公开书评（全部 / 推荐 / 不行 / 最新 / 一般，含星级与翻页）、相似书（含翻页）
- 书籍详情与目录：查看书籍基本信息与章节结构，封面、评分、阅读人数一目了然
- 所有书籍均可一键跳转微信读书 App（使用官方 `deepLink`，不自行拼接链接）

## v0.16.0 · 2026-10-04

「☁️ 官方数据」阅读行为报告补齐 V2「下半」，新增规律建议与笔记密度。

- 新增「十四、阅读规律与建议」：只用报告已有指标、按固定规则生成「事实句 + 温和建议」（时长节奏 / 阅读时段 / 偏好分类 / 完读率 / 笔记投入 / 书架规模），不编造数据、不下绝对化结论、不含健康建议；未配置 DeepSeek 时同样生成
- 「十、笔记行为」新增「10.2 笔记密度（衍生指标）」：平均每本笔记数、想法/点评占比、划线占比
- 自包含 HTML 导出（样式与图表脚本全内联、双击即看）沿用本轮图表能力

## v0.15.2 · 2026-10-04

## v0.15.0 · 2026-10-03

移除「主题设置」。

- 不再提供插件的明亮 / 暗黑 / 护眼主题切换与「使用官方主题」按钮。微信读书官方已自带主题切换，插件再做属于多余功能，故整体移除
- 其余功能（屏占比调节、自动阅读、快捷键、勿扰、全屏、阅读统计、笔记增强、官方数据）不受影响

## v0.14.1 · 2026-10-01

移除「点击笔记跳回原文」。

- 「📝 笔记」不再支持点条目跳转定位原文（翻页模式下无法可靠工作），仅保留面板内搜索定位；划线/想法聚合、一键复制、Markdown / 纯文本 / HTML / PDF 导出均不受影响

## v0.12.0 · 2026-09-29

笔记一键复制、官方数据报告升级为「深度画像」。

- 「📝 笔记」新增一键复制：富文本（可直接粘贴进文档）与 Markdown 两种；导出增加 HTML 与 PDF
- 「☁️ 官方数据」报告改为按深度画像组织：元信息 → 执行摘要 → 数据全景（核心指标 / 官方概要 / 偏好分类）→ 阅读轨迹与时间线 → 阅读时段分布 → 偏好画像（作者 / 出版社 / 版权方）→ 读得最多 → 书的印象 → 成就勋章 → 附录数据说明
- Markdown 与 HTML 导出共用同一份报告模型，避免两种格式内容漂移

## v0.11.0 · 2026-09-29

新增「官方数据」阅读行为报告。

- 新增「☁️ 官方数据」：粘贴自己的微信读书 `wrk-` Key，生成官方口径的阅读行为报告（总时长 / 阅读天数 / 自然日均 / 环比 + 时长分布 + 读得最多），支持本周 / 本月 / 本年 / 累计切换，可导出 Markdown / HTML / PDF
- 新增 `background.js` 与 `i.weread.qq.com` 主机权限：官方网关对带鉴权的跨域预检会失败，改由扩展身份请求，你的 Key 只发往官方网关
