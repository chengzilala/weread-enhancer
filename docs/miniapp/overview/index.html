微信小程序是什么

微信小程序「悦读且住」已正式上线：在微信里搜「悦读且住」就能打开，或在官网首页点「微信小程序」按钮扫码进入。打开它，就等于把「读完之后」的复盘装进了微信——不用装 App，随手就能看一眼。

它做什么、不做什么

做：读完之后的数据总览、阅读人格、阅读行为报告、书架、笔记，外加一个别人没有的「我的纸书」。

不做：屏占比、勿扰、全屏、自动阅读——那些属于「读的过程」，只装在电脑上的浏览器插件里。

和 H5 的最大差别：没有 AI

为了通过微信审核（个人主体不允许 AI 生成能力），小程序是合规精简版：

  • 小程序内不含任何 AI 生成；
  • 「每日卡片」「灵感漫游」在小程序里是纯本地排版——只把你的划线原文按主题摆出来，不做解读、不写文章；
  • 想体验 AI 成文的版本，请用 H5 移动端（满血版）。

开始用

  1. 打开小程序，进入底部「我的」；
  2. 粘贴 wrk- 开头的微信读书 Key（在微信读书 App 的「微信读书 Skill」页复制）；
  3. 点「保存并校验」，通过后回首页即可。

Key 只存手机本地，请求经云函数内存中转，不落库、不记原文。

想打开得更快？把它加到桌面 / 我的小程序

安卓可把小程序「添加到桌面」，iPhone 可「添加到我的小程序」——之后一点就能打开，不用每次在微信里找。分步做法见 加到手机桌面。

页面结构

底部五栏：首页 / 人格 / 报告 / 书架 / 我的

二级页面（从「我的 → 更多」等入口进入）：

  • 每日卡片与灵感漫游
  • 我的纸书
  • 关联网页账户
  • 笔记概览
  • 运营看板（只有作者本人可见）

换手机怎么找回数据

小程序默认用微信身份识别你，换手机、换微信号就找不回来了。解决办法是关联一次网页账户：之后阅读人格结果与昵称会在两端同步（见 关联网页账户）。
