插件里有两个功能要读「**你自己的**」微信读书数据：阅读洞察（阅读行为报告）、笔记的划线/想法。要拿到这些，得用你自己的 API Key。本篇把两把 Key 一次讲清：怎么来、怎么配、怎么删、有什么风险。

> 适用插件 **v0.17.0**（以代码为准）

## 一、Key 是什么，为什么需要

- **微信读书官方 API Key（`wrk-` 开头）**：插件拿它走微信读书官方网关（`i.weread.qq.com`）读取你自己的阅读数据。「阅读洞察」的报告、书架、搜书 / 书评 / 推荐，以及「笔记」的划线/想法都依赖它。
- 它不是插件账号，也不需要注册。它本质等于**你账号的读取权限**，所以必须只放在你自己这台电脑上。

> [!warning] 一句话记住
> Key 等于你账号的读取权限。只放本机，不发给任何人，不贴到聊天 / 截图 / 仓库。

## 二、怎么获取（`wrk-` Key）

1. 打开微信读书 App
2. 进「微信读书 Skill」页面
3. 复制 `wrk-` 开头的 API Key

## 三、怎么在插件里配置

1. 点插件悬浮球 → 菜单 →「🔑 API Key」
2. 把 `wrk-` Key 粘进输入框（默认是掩码，点「显示」可看明文）
3. 点「保存并校验」

「保存并校验」会先探一下网关连通性，再用一个需要登录的轻量接口确认真实有效，**通过后才写入**。

面板里能看到的按钮与状态：

| 按钮 | 作用 |
|---|---|
| 显示 / 隐藏 | 切换输入框明文 / 掩码 |
| 保存并校验 | 校验通过才保存 |
| 清除 Key | 删除本机保存的 Key |
| 刷新状态 | 重新拉取当前状态 |

状态字段：已配置 / 未配置 · 保存时间 · 最近校验时间 · skill 版本。

## 四、可选：DeepSeek Key（AI 增强）

- `sk-` 开头，**可选项**，不配不影响其它功能。
- 作用：让「阅读洞察」报告的「执行摘要」由 AI 生成一段人格化解读；**数字仍然由本机规则计算，不交给 AI 算**。不配则用默认的规则化摘要。
- 配置位置：同一个「🔑 API Key」面板里的「AI 增强（DeepSeek，可选）」区。

> [!warning] 隐私必须知道
> 启用 DeepSeek 后，生成报告时会把「笔记最多的几本书」的划线 / 想法**原文样本**发送给 `api.deepseek.com` 用于生成文字。介意就别配，不影响其它功能。

## 五、隐私与安全（红线）

- Key 只存在本机 `chrome.storage.local`：官方 Key 存 `wreOfficialSkill`，DeepSeek 存 `wreDeepSeekKey`，不上传（DeepSeek 例外见上）。
- 插件日志只输出**掩码**（形如 `wrk-****(36)`），不打印明文。
- 官方提醒：Key 等同账号读取权限，请勿粘贴到聊天、截图或提交到代码仓库；怀疑泄露可在 App 里重置。
- **不要把 Key 发给任何人**，包括「帮你配置」的人。

## 六、常见问题

| 情形 | 插件提示（以代码为准） | 你该做什么 |
|---|---|---|
| 未配置 | 尚未配置 API Key | 去「🔑 API Key」粘贴 |
| 格式不对 | Key 格式不对：应以 `wrk-` 开头 | 确认复制完整、没漏前缀 |
| 无效 / 失效 | API Key 无效或已失效（HTTP 401 / 403） | 回 App 重新获取 |
| 超时 | 请求超时（超过 10 秒） | 检查网络后重试 |
| 网络不通 | 网络不通或官方网关不可达 | 检查网络 / 代理 |
| 网关异常 | 官方网关返回异常 / 内容无法解析 / errcode 业务错误 | 稍后重试；持续失败走「支持与反馈」 |
| 需要升级 | 返回 `upgrade_info` | 更新插件版本 |
