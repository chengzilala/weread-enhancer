## 四、阅读行为报告（章节骨架对齐「深度阅读画像」）

- [ ] **4.1** 四个周期按钮「本周 / 本月 / 本年 / 累计」可点击，当前周期高亮
- [ ] **4.2** 报告顶部先显示「元信息表」（报告对象 / 数据来源 / 统计周期 / 生成时间 / skill 版本 / 分析方法 共 6 行）；「数据来源」行按**实际接入**的接口动态列出（本版含 `/readdata/detail · /shelf/sync · /user/notebooks`）；「报告对象」优先显示你的**真实微信读书昵称**（读不到时回退「微信读书用户（本机账号）」，控制台 `[official]` 可看到命中来源）
- [ ] **4.3** **一、执行摘要**：首段为一句总述（总时长 + 覆盖天数 + 自然日均），随后以列表给出环比 / 最集中周期 / 统计单元数 / 单元均值 / 官方偏好判定等解读；**本节固定基于「累计（总体）」数据，与顶部周期选择无关**——切换本周/本月/本年/累计，摘要数字不变，标题下方有口径提示 note（累计数据未取到时退回所选周期并提示）
- [ ] **4.4** 「共 N 个统计单元，其中 M 个有阅读记录」中 N（总数）与 M（有记录数）**不相等时数值正确**
- [ ] **4.5** **二、数据全景 · 2.1 核心指标**：四张卡片齐全（总时长 / 阅读天数 / 自然日均 / 较上期）
- [ ] **4.6** 总时长单位为秒换算后的可读文案（如「7 小时 46 分钟」），**不是**把秒数当分钟/小时直显
- [ ] **4.7** 「较上期」有数据时显示带符号百分比（如 `+59.8%` / `-71.3%`）；切「累计」显示 `—`
- [ ] **4.8** 切到「累计」：「自然日均」显示 `—`（官方该周期不返回），不是 `0 分钟`
- [ ] **4.9** **2.3 官方概要**：有 `readStat` 时以 chips 显示（读过/读完/阅读天数/笔记）；本周无此字段时该小节整体不出现、不报错
- [ ] **4.10** **2.4 偏好分类**：表格含「分类 / 读过 / 时长 / 占比」，含绿色条形列；表下方若官方给出 `preferCategoryWord` 则以 callout 显示「官方判定：…」
- [ ] **4.11** **三、阅读轨迹与时间线**：小节标题随周期变化——本周/本月=「每日阅读时长」、本年=「月度阅读时长」、累计=「年度阅读时长」
- [ ] **4.12** **重点（日期口径）**：本周分桶标签为最近两天真实日期；本年从「1 月」开始；累计为「20xx 年」
- [ ] **4.13** 表格按时间升序列出有阅读的周期，含时长、占比、条形长度（最长一行为满格）；若存在 0 时长桶，表下方出现「已隐藏 N 个 0 时长周期」
- [ ] **4.14** **四、阅读时段分布**：仅「累计」周期出现（官方仅该周期返回 `preferTime`）；表格含 7 个时段（清晨/上午/午间/下午/晚间/深夜/凌晨）与时长、占比、条形
- [ ] **4.15** 时段表下方出现「全天峰值出现在 HH:00 前后，…（占 X%）」note，且峰的 `HH` 与官方 `preferTime` 一致（索引 0 = 06:00）
- [ ] **4.16** **五、偏好画像**：按可得性分别出现 5.1 偏好作者（作者/本数/时长）/ 5.2 偏好出版社（出版社/本数）/ 5.3 偏好版权方（版权方/本数）三张子表，缺失的字段整节不出现

## 五、缓存与刷新

- [ ] **5.1** 首次拉取后，10 分钟内切走再切回同一周期：命中缓存（提示「来自 … 的缓存」），无新网络请求
- [ ] **5.2** 点「刷新」：强制重新拉取（Network 有新请求），提示变为「刚刚拉取 …」
- [ ] **5.3** 切换周期分别拉取，各周期缓存独立（互不串数据）
- [ ] **5.4** 刷新页面后：**Key 仍在**（持久化）；报告缓存仍在；周期选择回到默认「本月」（内存态，**属预期**）
- [ ] **5.5** **书架/笔记概览缓存**：首次拉取后 30 分钟内，**切换周期 / 重新打开面板**不会重新请求 `/shelf/sync` 与 `/user/notebooks`（Network 上这两路无新请求，仅报告主体按周期重新拉）；点「刷新」为强制全量，会重新请求这两路（属预期）
- [ ] **5.6** 书架或笔记**任一路失败**时，本次结果**不写入**概览缓存（下次打开会重试）

## 十、数据口径已知结论（用于对照，非勾选项）

- 官方所有时长字段单位是**秒**。
- 分桶时间戳是**「中国时区零点」编码成的 UTC 秒**（实测 `mod 86400 = 57600`），展示必须 +8h；直接按 UTC 会差一天/一年。
- 环比 `compare` **仅当前周期**返回；累计不返回 `dayAverageReadTime`。
- `readLongest` 官方已过滤低于约 5 分钟的内容。
- 本功能数据全部来自**官方 gateway**，与「📊 阅读统计」的**本地口径估算**是两套独立数据，不合并、不互相覆盖。
- `/shelf/sync` **无参数**；`albums[]` = 专辑/有声书（与 `books[]` 完全独立）；`mp` 仅表示「文章收藏」目录入口。
- 书架条目总数 = `books.length + albums.length +（mp 非空 ? 1 : 0）`；**禁止**只数 `books`，也**禁止**遍历 `books` 逐本调 `/book/info` 判断类型。
- 私密数 = `books[].secret==1 + albums[].albumInfoExtra.secret==1 +（mp 非空 ? 1 : 0）`（文章收藏入口固定计入私密）。
- `/user/notebooks` 为**游标分页**：首页只传 `count`，下一页用上一页最后一条的 `sort` 作 `lastSort`；不支持 `offset`/`limit`。
- 笔记数 = `reviewCount + noteCount + bookmarkCount`；`noteCount` 是**划线数**（不是总笔记数），`reviewCount` 已含个人点评（勿重复加）；书签只统计数量、不导出内容。
- `/readdata/detail` 与 `/shelf/sync`、`/user/notebooks` 的**业务参数必须平铺在 JSON body 顶层**（与 `api_name`、`skill_version` 同级），不要包进 `params`。
