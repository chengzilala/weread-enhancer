小程序里有 **6 个页面**能生成分享图，都是竖版 PNG，用你手机本地的画布绘制。

## 从哪生成

| 页面 | 按钮 |
|---|---|
| 首页 | 生成数据分享图 |
| 人格 | 生成竖版分享图 |
| 报告 | 生成报告分享图 |
| 书架 | 生成书架分享图 |
| 每日卡片 | 生成分享图 |
| 灵感漫游 | 生成分享图 |

## 生成之后怎么发

点按钮 → 弹出预览层，里面有两个选择：

- **转发给朋友**：调起微信的图片分享菜单，**不用先存相册**；
- **保存到相册**：存下来慢慢发。

预览层里的图片**长按也能转发**。

## 还有一种：小程序卡片

和分享图是两条独立通道——在页面里用微信的「转发」，或右上角「···」，生成的是**小程序卡片**，好友点开直接进入对应页面。

## 署名从哪来

分享图右下角的头像昵称，取自「**我的 → 我的资料**」里你填的内容。头像与昵称**只存本机、不上传**（昵称在关联网页账户后会同步到你的账户，头像始终不传）。
