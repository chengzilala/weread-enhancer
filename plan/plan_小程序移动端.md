## 1. 目标与成功标准

- **一句话目标**：用户在手机上粘贴一次自己的 `wrk-` Key，即可随时查看阅读数据、阅读人格、阅读行为报告，并能一键转发分享。
- **成功标准**：见 [RPD §7](./RPD_小程序移动端_需求文档.md)——Key 一次输入长期免输、核心数据/人格正确展示无白屏、异常有引导、能分享、提审通过。

## 5. 红线与约束（贯穿全程）

- **零外部依赖**：不引入第三方统计 / 广告 SDK。
- **旧代码不改，新功能写新模块**：抽取插件算法时不得改动插件现有行为。
- **Key 安全**：`wrk-` 微信读书 Key 与 `sk-` DeepSeek Key **默认仅存用户本机**（小程序 / 插件）；**H5 侧可按需把用户自填的 Key 加密托管在服务端**（须用户明示同意 + 隐私政策声明 + 可一键清除）。任何端都**不得把 Key 提交到代码仓库、不得写明文日志**（日志仅掩码）；云函数中转不持久化明文。
- **AI 边界**：人格与报告的主体仍是**本机规则计算**。**M15 合规整改后（2026-10-06）**：小程序端**整体关闭 AI**（`config.AI_ENABLED=false` + 云函数 `action:'ai'` 硬阻断），原「人格画像润色 / 每日卡片 / 灵感漫游」三处改为**纯本地规则排版**，小程序内不产生任何 AI 内容；**AI 仅保留在 web 侧**（插件 / 官网 / H5），且**不得在小程序内出现任何站外 AI 引导**。后续若转企业主体，再经 `AI_ENABLED` 重新放开。
- **云同步边界**：只存「本机算出的人格结果视图」，按 openid 隔离；不存 Key、不存官方接口原始数据。
- **文案以代码实测为准**：权限 / 域名 / 数据来源说明不夸大。
