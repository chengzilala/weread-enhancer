关于分类

阅读体验

阅读统计与导出

统计前台阅读时长（今日 / 本周 / 本月 / 本书），一键导出 HTML 报表 / PDF / Markdown / CSV / JSON。

笔记增强

把本书全部划线与想法按章节聚合，搜索定位、一键复制、多格式导出。

阅读洞察

拉取官方口径的阅读行为报告，并附「书架」与「发现」两个页签（搜书、书评、推荐）。
