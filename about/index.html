一句话说清

微信悦读不是「一个插件」，而是围绕微信读书的一套产品：读的时候让页面更顺手，读完之后把数据、笔记和想法接起来。

同一套东西，有三个入口，按「你在哪读、想干什么」分开。

三个入口，同一个产品

入口在哪用管什么
浏览器扩展电脑上的 Edge / Chrome / 360 浏览器读的过程：屏占比、自动阅读、阅读统计、笔记增强、阅读洞察
H5 网页版手机浏览器打开 /app/读完之后：数据总览、阅读人格、行为报告、每日卡片、灵感漫游（保留 AI 深度解析）
微信小程序「悦读且住」微信里搜名字 / 扫码打开读完之后：复盘数据、阅读人格、报告、我的纸书、每日卡片（合规精简版，不含 AI）

三者各自独立，不必都装、也不必都注册：想少打扰就只装扩展；想读完复盘，用网页版或小程序就行；小程序还能关联网页账户，两边数据对得上。

一、浏览器扩展：管「读的过程」

装在电脑浏览器里，作用范围只有 https://weread.qq.com 这一个网站。它解决的是「读书时手边那点别扭」：

  • 屏占比调节：正文放宽、两侧留白收起来，一屏多读几行
  • 自动阅读：不用一直动鼠标，让它自己翻（空格开始 / 暂停）
  • 阅读统计：这次读了多少、多久，心里有数
  • 笔记增强：把划线和想法整理、导出，散落在书里的东西收得回来
  • 阅读洞察：用你自己的 Key 读你自己的官方数据，看成体系的书单与偏好
  • 另有 阅读人格、语音复习、本地找书、数据备份与恢复 等小模块

已在 Edge 商店 和 360 应用市场 上架。

二、H5 网页版：管「读完之后」

手机浏览器打开 /app/ 就能用，不用安装，和官网同域、共用一个账户。

它的重心不是「读」，而是把读完的书变成看得见的东西：数据总览、阅读人格（4 位人格代码 + 16 型「读书人」称号）、阅读行为报告、每日卡片、灵感漫游，以及朗读与分享。这一端保留 AI 深度解析。

三、微信小程序「悦读且住」：微信里随手看

在微信里搜「悦读且住」就能打开，不用跳出微信。定位是合规精简版：只做复盘数据、阅读人格、行为报告、我的纸书（扫码加书）、每日卡片与灵感漫游，不含 AI。

它可以和网页版账户关联，所以在电脑上配好的东西，微信里也能看到。

为什么做

微信读书网页版本身已经很干净，但用久了总有些「差一点」的地方——正文两侧留白太多、晚上白底刺眼、翻页要一直动鼠标；读完之后又不知道自己读了多少，划线散落在书里找不回来。

这些都不是大问题，但每天都会遇到。于是把「读的过程」做成扩展，把「读完之后的复盘」做成网页版和小程序，一件一件补齐。

它不做什么

  • 不上传阅读数据，不内嵌第三方统计与广告代码（唯一的匿名使用统计为自建，只发随机匿名标识 + 版本号 + 日期 + 事件名，默认开启、可一键关闭）
  • 不改微信读书的账号体系，不代你操作账号
  • 不读取这本书以外的任何页面（扩展只在 weread.qq.com 运行）
  • 不做付费墙：功能全开，不卖会员

对外请求只有两类：① 默认开启、可关闭的匿名使用统计；②「阅读洞察」——用你自己的 Key，向微信读书官方网关请求你自己的数据，必须由你主动配置后才生效。详见隐私政策。

技术口径

  • 扩展：Manifest V3 + 原生 HTML / CSS / JS，零外部依赖，权限只要 storage
  • 快捷键只有四个：空格 / D / F / ?
  • 网站：Python 标准库静态编译；H5 与小程序共用同一套视觉与模块口径
