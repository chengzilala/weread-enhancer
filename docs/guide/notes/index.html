笔记增强：划线与想法一键留存

书读完了，划线留在微信读书里，下次想找却翻不到。「笔记」面板把这些内容集中起来，变成你自己的东西。

三个能力

1. 划线 / 想法聚合

悬浮球 → 菜单 → 「📝 笔记」：

  • 按章节分组展示，两个页签切换划线 / 想法
  • 每条显示原文、你的想法与时间
  • 顶部搜索框输入关键词，实时定位某条笔记

2. 批量导出与一键复制

导出：

  • Markdown：# 《书名》读书笔记 + 按章节的划线清单 + 想法小节
  • 纯文本：【章节】 开头的编号清单
  • HTML / PDF：适合直接存档或分享的报表

一键复制：

  • 富文本：复制后可直接粘贴进 Word / 飞书 / 公众号编辑器，保留格式
  • Markdown：粘贴进 Obsidian 等笔记软件

导出文件带书名与日期，丢进笔记库不会覆盖。

3. 选中即复制

在正文里选中一段文字，选区下方会出现「📋 复制」浮标。复制时会自动去掉微信读书附加的版权声明水印。

面板数据不落盘

笔记内容只在内存里短暂缓存，关掉页面就没了；导出文件保存在你自己的电脑上。
