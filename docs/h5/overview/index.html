H5 移动端是什么

插件管的是「读的过程」，但它只装在电脑浏览器里。H5 移动端补上另一半：读完之后在手机上复盘。

它是什么

一个纯网页的微信悦读，用手机浏览器打开就能用：

https://reader.chesterlee.cn/app/

也可以从本站首页的「H5 移动端」按钮进去。

它不需要安装任何东西，不占内存；想用得更像 App，可以「添加到主屏幕」（见 加到手机桌面）。

和插件、小程序的分工

装在哪儿擅长什么AI
浏览器插件电脑浏览器读的过程：屏占比、自动阅读、笔记有（可选 DeepSeek）
H5 移动端手机浏览器读完之后：数据、人格、报告、卡片、漫游有（保留 AI）
微信小程序微信里读完之后 + 纸书管理无（合规精简版）

一句话记住：插件管读，移动端管复盘；H5 是「满血版」，小程序是「合规版」。

用之前：准备一把 Key

移动端的数据来自微信读书官方接口，需要你自己的 Key：

  1. 在微信读书 App 里进入「微信读书 Skill」页面，复制 wrk- 开头的 Key；
  2. 回到 H5，首次打开会停在引导页，把 Key 粘进去；
  3. 点「保存并校验」，通过后进入首页。

以后换设备不用再找这把 Key——用账户码就能登录回来（见 账户与跨设备）。

Key 只提交一次

H5 会把 Key 加密托管在你自己的云函数里，本机只留掩码，页面里再也看不到明文；随时可在「我的」里一键清除。详见 API Key 使用说明。

进去之后看到什么

底部五栏：

  • 首页：本周 / 本月 / 本年 / 累计的总时长、趋势、指标、偏好、读得最多
  • 人格：从你的数据里算出 4 位人格代码与 16 型称号（详见 阅读人格是什么）
  • 报告：分章节的阅读行为报告
  • 书架：电子书 / 专辑 / 公众号概览
  • 我的：账户码、Key 状态、每日卡片与灵感漫游的往期入口

二级页面（点进去后左上角返回）：

  • 每日卡片：用你的划线 / 想法生成一张卡片
  • 灵感漫游：AI 写的主题深度综述
  • 运营看板：只有作者本人可见

数据都在你这边算

阅读数据、人格判定、报告全部在你的手机浏览器里按固定规则算出；需要 AI 时，才经你自己的云函数中转。不上传书目、笔记等原始内容。
