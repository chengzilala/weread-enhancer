> [!note] 关于版本号
> 网站页脚显示的版本号、以及插件查询的「最新版本」，都直接读扩展的 `manifest.json`，不存在两处手写版本号的问题。

## v0.14.1 · 2026-10-01

移除「点击笔记跳回原文」。

- 「📝 笔记」不再支持点条目跳转定位原文（翻页模式下无法可靠工作），仅保留面板内搜索定位；划线/想法聚合、一键复制、Markdown / 纯文本 / HTML / PDF 导出均不受影响

## v0.12.0 · 2026-09-29

笔记一键复制、官方数据报告升级为「深度画像」。

- 「📝 笔记」新增一键复制：富文本（可直接粘贴进文档）与 Markdown 两种；导出增加 HTML 与 PDF
- 「☁️ 官方数据」报告改为按深度画像组织：元信息 → 执行摘要 → 数据全景（核心指标 / 官方概要 / 偏好分类）→ 阅读轨迹与时间线 → 阅读时段分布 → 偏好画像（作者 / 出版社 / 版权方）→ 读得最多 → 书的印象 → 成就勋章 → 附录数据说明
- Markdown 与 HTML 导出共用同一份报告模型，避免两种格式内容漂移

## v0.11.0 · 2026-09-29

新增「官方数据」阅读行为报告。

- 新增「☁️ 官方数据」：粘贴自己的微信读书 `wrk-` Key，生成官方口径的阅读行为报告（总时长 / 阅读天数 / 自然日均 / 环比 + 时长分布 + 读得最多），支持本周 / 本月 / 本年 / 累计切换，可导出 Markdown / HTML / PDF
- 新增 `background.js` 与 `i.weread.qq.com` 主机权限：官方网关对带鉴权的跨域预检会失败，改由扩展身份请求，你的 Key 只发往官方网关

## v0.10.0 · 2026-09-29

- 新增「📝 笔记」：按章节聚合本书全部划线与想法；支持 Markdown / 纯文本批量导出
- 新增选中即复制：选中正文后弹出「📋 复制」，并自动清洗微信读书附加的版权声明

## v0.9.0 · 2026-09-29

- 新增「📊 阅读统计」：今日 / 本周 / 本月 / 本书时长，当前书籍进度与最近 10 本书
- 支持五种导出：JSON / CSV / Markdown / HTML 报表 / PDF
- 统计口径只计算页面在前台且停留在阅读页的时间；代码开始按 `modules/` 模块化组织

## v0.8.3 · 2026-09-29

- 修复：屏占比高时的透明感应层会挡住官方翻页点击区，改为按鼠标坐标判定，零遮挡
- 交互：悬浮球由「点击展开」改为「悬停即展开」，移开 250ms 收起

## 更早的版本

v0.8.0 及以上版本的完整历程见仓库内 `plan/version_plan.md`。本站更新日志从 v0.8.3 起逐版记录。
