本地找书：给书架补上标签与搜索

书一多，微信读书自带的书架就不够用了：不能打标签，搜索也只能搜书名。「找书」给书架补上两块能力——本机标签和多维度搜索。

从哪打开

悬浮球 → 菜单 → 🔎 找书。

它要读你的书架，所以需要先在 API Key 使用说明 里配好 wrk- 开头的官方 Key；没配时面板会给出「去配置 API Key」的引导。

一、本机标签

给任意一本书加上你自己的标签，比如「一号书柜」「借出中」「专业必读」。

  • 在书籍条目的「+ 加标签」里输入即可，标签名最多 20 字，每本书最多 10 个。
  • 面板右上「标签管理」能重命名 / 合并 / 删除：重命名和合并会同时更新所有挂了该标签的书；删除只移除标签，不删书。
  • 标签区还有「同时命中 (AND) / 任一命中 (OR)」两种匹配模式。

标签只存本机

标签只存在你浏览器本地（chrome.storage.local），不上传、不写回微信读书。官方接口全程只读。 换电脑或清缓存前，记得去 数据备份与恢复 导出备份，否则标签会永久丢失。

二、多维度搜索

搜索框支持按书名 / 作者 / 标签 / 官方分组匹配，还能用拼音首字母——输入 rzjx 就能命中《认知觉醒》（拼音只参与命中，不参与高亮）。

下面有三行筛选，可以叠加：

筛选行选项
状态全部状态 / 在读 / 已读完 / 从未打开
笔记笔记不限 / 无笔记 / 有笔记 / 1-10 条 / 11-50 条 / 50 条以上
时间时间不限 / 近 7 天 / 近 30 天 / 近 90 天 / 更早

往下还有「按标签筛选」和「官方分组」（来自官方书架，只读，多选任一命中）。

三、连笔记正文一起搜

列表里有个「搜我的划线 / 想法」按钮：点下去会逐本拉取有笔记的书，在划线正文和想法正文里找关键词。命中会在条目下显示「命中划线：…」或「命中想法：…」（截断展示）。

这个过程要一本本查，面板会显示「已查 N / M」进度，随时可以「停止」。

打开与刷新

  • 点条目「打开 ↗」会在新标签页打开网页版书籍详情，电脑上直接能看。
  • 「刷新书架」重新拉取（书架缓存 30 分钟）。
  • 结果多时点「显示更多」分页展开。
