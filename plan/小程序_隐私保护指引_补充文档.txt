《悦读且住》小程序 · 个人信息处理补充说明

更新日期：2026-10-15

一、总原则
本小程序是一款「个人阅读数据展示工具」：用户粘贴本人的微信读书 API Key 后，以本人身份调用微信读书官方接口读取其阅读数据，并在本机生成阅读报告与趣味阅读人格。本小程序不提供内容发布、交易或社交服务，不采集与阅读无关的个人信息，不向任何第三方出售、共享或转让个人信息。

二、仅保存在你本机的信息（不上传服务器）
1. 你粘贴的「微信读书 API Key」：仅保存在本机微信本地缓存中，卸载小程序或清理缓存即丢失；调用时经微信云函数内存中转访问官方接口，不落库、不留存。
2. 你自选的头像：仅保存在本机用户目录，用于「我的」页展示与分享图署名。
3. 本机生成的报告、人格、纸书等数据：默认保存在本机。

三、保存在微信云开发（腾讯云）的信息
以下信息全部按你的用户标识（openid）隔离存储，仅你本人可读写：
1. 阅读人格结果：为使你换设备或重装后仍能快速看到此前算出的「阅读人格」，会保存人格结果视图（不含阅读原文、不含 API Key，上限 400KB）；已关联网页账户时，按你主动生成的账户码存储同一份数据。
2. 「我的纸书」云端备份：仅在你主动点击备份时保存纸书档案（书名、ISBN、关联书目等），不含 API Key。
3. 昵称：在你主动关联网页账户并填写昵称后，昵称随账户同步，用于跨设备保持一致（头像不同步）；你可在「我的」页随时清除。
4. 小程序使用量统计：每次打开小程序记录一条「使用」事件，按用户标识按天去重，仅含「用户标识 + 日期 + 次数」，不含阅读数据、笔记、API Key 或 IP；仅用于汇总「今日活跃人数 / 累计人数」，数据保留 90 天，超期仅保留计数。
5. 只读分享短链：当你在分享弹层点击「复制分享链接」时，把该卡片上本就用于展示的字段（标题、数据指标、划线/想法原文、来源出处、昵称署名）存为一条短码记录，便于好友凭链接查看同一张卡片；该记录不含 API Key、不含账号标识，90 天后自动失效。

四、信息对外提供
除为提供服务所必需的微信云开发（腾讯云）存储外，不向任何第三方提供、共享、转让或公开披露你的个人信息；本小程序未接入任何第三方统计、广告或内容类 SDK。

五、删除方式
1. 本机数据：在「我的」页清除本机数据，或卸载小程序。
2. 云端数据：可通过下方联系方式要求删除你的云端记录（人格结果、纸书备份、昵称、统计去重键），我们承诺在十五个工作日内完成核查与处理。
